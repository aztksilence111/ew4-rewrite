# 0.2.36：征服通关国旗

征服选择界面现会在对应剧本卡片标题下显示已通关国家的旗帜，与原版行为一致。

- 单人征服胜利后记录国家，重复通关只显示一面旗，多个国家可累积；重新进入征服菜单即可刷新，重启后保留。
- 支持 Mod 定义的国家旗帜，通关记录沿用各 Mod／逻辑版本的账户隔离。
- 兼容旧账户与旧存档：重新载入旧的已胜利存档可补记国旗，不重复发奖。若旧记录已无对应胜利存档，无法还原当时所用国家。
- 保留 0.2.35 的界面尺寸、自定义音频、整编滑动和移动端优化等更新。

Android 版本号39，提供 ARM64／x64 通用 APK；Windows Web 包自带运行时。继续使用原 Android 应用标识与签名，覆盖安装前建议导出存档。主菜单和对局暂停后的设定均保留存档导出入口。

规则 API 仍为3。配套 Mod 作者工具包1.1.1使用本版运行库与相同资源基础；既有合法 Mod 接口和规则指纹输入保持。

验证结果见同版本发布记录。Android 包体和双 ABI 托管程序集在桌面进行校验；未进行 ARM64 手机设备验收。
