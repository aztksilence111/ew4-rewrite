# Chromium 70 frontend build

Run `npm --prefix tools/frontend ci --no-audit --no-fund` once after checkout.
Web and Android builds both invoke `build.cjs` through `rewrite/Frontend.Build.targets`.
Node.js must be on PATH. Builds never fetch tooling automatically.

The pinned esbuild version lowers every game/vendor script to Chrome 70 + ES2018.
Acorn rejects newer output syntax. CSS inset becomes four physical properties;
relative image URLs account for the generated `wwwroot/compat/` location.
Generated files are ignored; sources remain in `wwwroot/`. ModStore rewrites the
HTML script and stylesheet references to these same outputs on Web and Android,
and preserves the existing per-content resource revisions. Do not copy raw JS
over the generated outputs when publishing. Missing build tools fail the build.
The manifest ties generated bytes to source SHA-256; the APK checker verifies both.

`startup.js` supplies only missing runtime APIs and diagnostics. `runtime-compat`
handles unsupported CSS layout features. Pixi uses the existing shared draw API;
WebGL initialization failure uses Canvas 2D, rebuilding the canvas and input
listeners if the original canvas already acquired a WebGL context. `?renderer=canvas`
provides a reproducible comparison path. Game rules/saves are shared.

Local Web previews (`localhost`, `127.0.0.1`, and `[::1]`) reset music and sound
to zero on each page load, including when storage contains audible settings.
Sliders can enable audio for the current test; Android keeps its saved volumes.
Automated audio checks use `--mute-audio` to exercise playback silently.

For an actual old engine, download an official Chromium snapshot into `build/`
and run `node tools/frontend/verify.cjs <chrome.exe> <preview-url> <report-folder>`.
The test uses CDP directly because modern Playwright is incompatible with that
old protocol. It records the engine's real User-Agent, menus, both draw paths,
rendered pixels, input, save/load, browser errors, and screenshots. Run once with
the old engine and once with the current browser. User-Agent spoofing is not used.

This validates a desktop Chromium engine, not Android's GPU, WebView integration,
touch hardware or long-running thermal behavior. Mate 30 Pro still needs testing.
