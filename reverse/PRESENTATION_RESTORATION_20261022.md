# r版表现修复与手感恢复

日期：2026-10-22。继[外部报告核查](R_VERSION_PRESENTATION_AUDIT_20261022.md)后，按用户“评估哪些应该修改用于优化和还原玩家手感”“按你说的先做”的授权实施。附件中的执行建议仍只作参考，本次没有运行附件脚本。

## 本次实现

| 核查编号 | 实现与效果 |
| --- | --- |
| PV-01 | `effects.attackPlan` 将完整兵模片段与既有命中/等待基准分开。attack、reload、finish按资源长度播放，余下恢复帧由渲染器退出，不加长输入等待。新的移动、战斗、场景切换及跳过会清理相应旧动作。 |
| PV-02 | 本方行动部队选中播放ready，完成停在静态attack；取消播放undoready后回静态ready，缺少取消片段时直接回静态ready。敌军选择不触发ready，施工继续使用原脚手架。 |
| PV-03 | 粒子按quantity发射率、时间轨和小数余量产生；once结束后停发并保留尾粒子，每发射器最多100颗存活粒子。固定1/60模拟步长使跨帧推进稳定，长时间跳帧只补算最近有效寿命范围。 |
| PV-04 | 位移、重力与旋转逐步积累；减速不再把已有位移重算回出生点。使用独立表现随机数，不调用游戏规则随机数。 |
| PV-05 | 粒子绘制按eff裁片refx/refy及目标尺寸计算参考点，保留现有纹理染色缓存与混合方式。 |
| PV-06 | 尾迹按grade 0/1/其他选择moving1/2/3，海面选择4；每次移动保留持续发射器，移除每50ms重建与陆地0.35经验缩量。旧粒子保持出生位置，移动结束后自然消失；屏外推进时不重播历史出生，仍跳过纹理绘制。 |
| PV-07 | 招募从-60线性落入，普通招募notice才播放招募表现；炮台施工与事件新增单位绕过普通落入/声音。**保留当前480/√speed毫秒时长**，没有直接改成187.5墙钟毫秒。 |
| PV-08 | 补接移动、普通招募、占领、医疗补给声音：移动按水域/骑兵/装甲分支；占领仅实际变更归属的非农场建筑；医疗消费结果显式透传suppliedUnit并触发恢复特效。撤回、跳过和读档不重播这些声音。音源预载并复用，重叠声音使用独立voice。 |
| PV-09 | 旧APK转换器在缺少def_motion时也可转换声音/效果/元素；声音白名单合并源WAV/OGG及被效果引用的MP3，后者同时进入sounds目录。纯数据补丁不额外快照effects.json。新增导入夹具验证原字节和存档隔离。 |
| PV-10 | 活着且非死亡展示中的炮台按clamp(floor((maxHP-HP)/80),0,3)绘制damaged烟雾，使用原def_elementanim分组与偏移，独立于burning火焰。 |

这完成10组问题中的有证据部分；PV-07的绝对速度以及其他尚待证明的原版细节不计为完全还原。

## 同步与兼容边界

- 保留攻击/反击首发对齐、共享impactAt及原阻塞等待公式。没有改伤害结算、AI、RNG、存档格式和跳过快进规则。原有死亡500ms淡出、guns命中选择、撤回朝向及旗帜图层保持。
- `presentation.json`单独保存基础动作音效/元素定义；旧Mod若覆盖旧effects.json但缺少新增字段，可回退这些定义，无需改包或重置存档。Mod显式提供elements时继续采用其配置。
- 7个动作音效从原始资源按字节复制，导出工具可再生。基础manifest的SHA256仍为`127952c0202a36bd4c56cdee5e23859f84b10ce156b800836092251f87fa6b9a`；基础Mod身份不因本轮表现资源变化而重置。
- BILE状态/缓存重写、非零motion index实际触发、image列表删除、quantity字节窄化、全局GameSpeed/暂停、WebAudio替换和渲染后端重写仍未实施。
- 补给表现当前针对明确的医疗消费分支；成长、升级及扩展技能治疗的原版附属表现未推广接入。
