# 物品数量和贴图

0.2.45起，原版非消耗装备不再隐式限制每ID只持有一件。同一ID可反复购买；显式配置的商店库存与规则仍有效。

所有旧ID和资源名保留，不要求迁移存档。界面仅合并完整定义属性及最终效果相同的物品数量；具有独立itemBindings的ID不合并。Mod仍可修改某个旧ID，使其单独显示和执行规则。

游戏设定“物品贴图／物品图库”按当前物品资源名列出图片，相同资源名的原版重复ID共用上传贴图，Mod独立资源名分别列出。玩家上传图片保存到当前内容档案的item-textures目录，并随存档原字节导出导入，不修改安装资源。恢复默认会重新使用当前Mod或原版图片。

支持PNG/JPG/WebP、单图≤10 MiB、最长边≤4096像素。等比缩放及位置调整后输出128×128透明PNG，商店、背包、装备同步显示。
