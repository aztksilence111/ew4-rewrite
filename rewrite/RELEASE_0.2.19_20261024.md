# 0.2.19：菜单比例与本地多人中立国修复

2026-10-24。Windows x64 独立 Web 包与 Android ARM64 APK（版本码 22）。规则 API 2，沿用既有 Android 签名。精确源码、包大小和 SHA-256 见 release-manifest.json 与 SHA256SUMS.txt。

- APK 剧本外菜单恢复原画布等比缩放并居中，空余区域留灰色，修正主菜单背景横向拉伸和征服两列距离过大。
- 主菜单、战役、征服、选国、教程及指挥部共用等比布局；剧本内战场和控件继续保留全屏适配。
- 修正旧版 WebView 的竖屏菜单兼容覆盖，避免指挥部和设置按钮被裁切。
- 战役与征服本地多人统一排除中立阵营，可选列表、全选和开局校验同步生效，重新开始也排除中立国。旧存档直接载入保留原局座位。
- 继承 0.2.18 的运输、经济面板、音乐及网格修复。

发行包不包含玩家账户或存档。已完成全部 87 战役和 6 征服的中立国选择检查、菜单与剧本内布局、实际 Chromium 70 兼容验证；APK 显示仍需真机复测。

构建与校验记录见[发布进度](https://github.com/aztksilence111/ew4-rewrite/blob/main/rewrite/RELEASE_PROGRESS_0.2.19_20261024.md)。
