# 0.2.33 — 友方领土运输船改造修复

Android ARM64（versionCode 36）及独立 Windows x64 Web，规则 API 3。

- 修复本方部队在友方领土上无法改造运输船的问题。报价、按钮和实际购买均按当前同盟关系判断，支持同阵营及外交结盟；扣除本方资源，保留行动点与友方领土归属。
- 修复同时占空中和地表的复合部队在陆地落点的占领、驻军与建筑状态，飞越路径和水上落点按分层规则处理；同步移动、AI 投影和撤回。
- 补充 Mod 可选的空层移动消耗、剧情生成部队立即行动、建筑及将领显示映射、组合动作和选中／取消动画接口，并更新接口说明。未配置的本体继续使用默认行为。
- 纳入相关地图点选、动作衔接与显示修订；独立 Mod 的人物、美术、剧本和本地试玩安装继续独立维护，不随本体包分发。
- 修复竖屏下单项操作确认按钮可能超出屏幕右缘的问题。

主菜单和对局暂停设定继续提供存档导出，保留账户、各槽和备份原始字节与校验信息，排除安装内容及启动缓存；保留存档 ZIP 导入和 Mod 隔离。

Android 应用 ID 与原签名保持，可覆盖安装。Windows 请完整解压 ZIP 后运行 `Start-Web.cmd`。附件包含 `SHA256SUMS.txt` 与 `release-manifest.json`。

已进行开发侧回归及实际双端包内容、签名连续性、ARM64 运行库和 16 KiB 对齐核验；本批没有 Android 真机安装验收。
