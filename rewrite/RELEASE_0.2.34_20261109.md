# 0.2.34 — MuMu 模拟器启动兼容修复

Android ARM64＋x64 通用 APK（versionCode 37），独立 Windows x64 Web，规则 API 3。

- Android 正式 APK 同时包含 ARM64 和 x64 运行库。ARM64 手机继续使用 ARM64；MuMu 等 x64 模拟器自动使用原生 x64，避免上一版 ARM64 转译启动时的长时间停顿。
- 增加 Android 原生启动阶段日志，方便定位资源检查和 WebView 初始化问题。账户、存档、已安装 Mod 与游戏规则保持兼容。
- 发行封包和校验同时检查两个 ABI 的完整性、架构及 16 KiB 对齐，防止再次仅发布 ARM64 而遗漏模拟器原生支持。

包含 0.2.33 的友方领土运输船改造修复及全部 R 版更新。双端主菜单和对局暂停设定继续提供原始字节存档导出及 ZIP 导入。

本机 MuMu 6.8.8.0／Android 12 用同源码 ARM64 与 x64 独立安装对照，x64 原生包正常进入主菜单。正式通用包已覆盖安装，系统选择原生 x64，两次冷进程启动分别约 17 秒和 5 秒进入主菜单，设定页面及存档导出入口正常。两个 ABI 的实际 APK 程序集均通过资源检查22项、存档导出35项和导入41项；Windows发布目录3399项通过。没有 ARM64 手机实机验收。

Android 应用 ID 与原签名保持，直接覆盖安装，无须卸载或清数据。Windows 完整解压后运行 `Start-Web.cmd`。附件提供 `SHA256SUMS.txt` 与 `release-manifest.json`。
