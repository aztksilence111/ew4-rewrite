# 将领皮肤最小示例

将本目录的 `rewrite/` 合并到作者覆盖包；若已有extension/metagame配置，请合并字段及目标数组，保留原规则。需要包含头像图库的API 3宿主。

示例为拿破仑（`ew4.commander.1`）增加“远征服”：拥有任意一位将领后完成内部目标，自动解锁并选用；玩家可在指挥部详情“皮肤”中切换。两张PNG是本仓库脚本生成的几何人物示意，不是正式人物美术；运行 `python generate.py` 可重建。替换为自己的合法PNG即可制作正式皮肤。

图像分别为384×384立绘和128×128小头像，后者可单独构图。玩家自行上传的PNG/JPG/WebP无需改包；格式、尺寸与接口字段见[完整说明](../../docs/porting/COMMANDER_SKINS.md)。
