## 已实现

- `Ew4.Core`：C#12，目标.NET Standard2.1，无第三方运行依赖，不依赖Android入口或绘图库。
- 战斗伤害、攻击次数、随机状态、将领/装备效果、六角坐标、加权寻路、粮食/士气、单人胜负与动画层时序。
- 势力/类别/等级/技能/装备使用稳定字符串ID与动态集合。旧数字映射只出现在导入和兼容模块。
- 寻路没有原版4000条记录数组；配置规则仍可以限制行动预算，未把地图越大当成越好。
- 装备容量作为传入配置；测试覆盖100技能、10装备以及超出配置的拒绝。
- 默认修正反击攻城炮误读建筑类型；显式兼容选项可复现原包。
- 不合法动作/数据抛出带错误码的异常；失败的战斗计算不会消耗调用方随机状态。
- 动态世界快照、可配置每格/每势力部队容量、事件顺序/对白等待、环境扩散与势力出局转移。
- `Ew4.Persistence`：.NET10存档适配器，版本4 UTF-8 JSON、摘要/内容版本校验、原子替换与上一版备份；核心仍无第三方运行依赖。版本1/2/3需显式迁移，目前拒绝读取。
- 动态经验阶段、可配置起火/衰减、单位刷新/势力存续，以及AI待机评分/类别请求/稳定选择；完整动作与AI仍待接通。
- 世界状态上的招募、工事创建及移动占领；包含修订号、资源、配置容量、对白阻塞和出局移交。
- 可恢复的势力/整轮切换，治疗/灾害/收入/粮食/士气刷新、建筑周边扩张及回合限时胜负；跨轮对白期间可保存恢复。
- 世界攻击提交、死亡/退场/出局、动态击杀统计、部队/军衔/爵位经验、起火/设施损毁和死亡对白队列；自动附带伤害及无副作用预览已接入。
- 地图战斗上下文：地形/设施/建筑回避、AI追加回避、等级装甲和相邻将领攻防；围城术保留建筑以外的AI回避。
- 世界培训与建筑升级：动态培训阶段/将领能力、费用/治疗、建筑升级路径、折扣、每回合次数与读档/轮转恢复。
- AI地块/兵力/攻击评分、战术移动/组合攻击、战略目标/有向长期路线/运输与稳定选择；动态世界生产、统一单位调度及失败生产随机提交。步骤已衔接生产/派遣/单位/回合。
- 将领挂接/更换/卸任/按回合与资源部署，保存基础属性防止重复加成；动态经验/能力继承计算已对照原函数，局外名册与勋章账户事务仍欠缺。
- 战斗和配置致命灾害共用死亡/将领退场/事件/出局处理；死亡对白期间可保存，确认后继续轮转，不重复灾害结算。默认仍保持原灾害非致命。
- 防御设施与运输购买，按技能减价、可配置建造/运输类别和海格政策；直接影响地图防御与海格移动。
