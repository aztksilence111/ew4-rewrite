# 0.2.21：玩家 AI 设定、部队容量与战役科技

2026-10-26。Windows x64 独立 Web 包与 Android ARM64 APK（版本码 24），规则 API 3，沿用既有 Android 签名。源码版本、文件大小和 SHA-256 见随包清单。

- 新增玩家 AI 设定：六类方针、框选或单选部队、最多32个有序目标，支持优先级调整、取消选中、红箭头与连线、AI标记及存档恢复。方针、部队和目标确认后才能开始，停止后不再接管玩家回合。
- 新增势力总部队容量：城市、工厂和马厩提供容量，玩家与 AI 共用限制；失城超限保留已有部队，限制继续扩军。顶部显示当前部队数、上限和回合数。
- 恢复战役兵种科技：原版五类22项，按战区升级、支付科技星数并保存，开局和存档携带科技快照；普通步兵不额外附送运输。
- 修复 AI 缺粮时继续扩军、当前势力败退后的回合推进，以及教程通知接口缺失导致按钮操作后弹出 `this.api.tutorialUi is not a function`。
- 更新东亚地图的河湖、地名、城市及省域设施，修复远景名称位置和已释放工厂纹理的恢复。
- 启动时根据原始 XML/BTL/BIN 和资源摘要自动重建转换缓存；未变化时复用缓存，配置变更后的存档按内容隔离。
- Web 包包含更新后的 Mod 作者接口、配置指南和最小示例。

日本、神罗新图仍处于地图制作阶段，本版不新增其可玩剧本。发行包不包含玩家账户、存档或已安装 Mod。桌面及浏览器检查、APK 内容/程序集、签名和16KiB对齐验证见[发布进度](https://github.com/aztksilence111/ew4-rewrite/blob/main/rewrite/RELEASE_PROGRESS_0.2.21_20261026.md)；Android 真机安装、实际显示与性能尚未验收。
