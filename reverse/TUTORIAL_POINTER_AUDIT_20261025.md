# 教程指示手显示核查

日期：2026-10-25。用户要求核查，本轮未修改游戏实现。

## 结论

已复现显示缺陷，原因在前端定位和目标绑定。原版指示手资源存在且可正常加载，并非缺图。

1. 资源栏指示手超出屏幕。`style.css` 把伪元素固定放在框上方 `top:-26px`，没有顶部碰撞处理。基础教程第二段实际框顶在3.48至4.17px，指示手顶为-22.52至-21.83px；24px高的容器只剩约1.48至2.17px在视口内，动画还会上移8px。桌面1280×720、横屏844×390、竖屏390×844均复现。
2. 进阶教程物品列表提示完全消失。真实流程推进至 `draw ui rect string=lbox_item row=2` 后，`#tutorial-focus.hidden=true`。原生窗口有一个 `[data-native-id="lbox_item"]`，但定位器只查 `[data-tutorial-id="lbox_item"]`，匹配数为0。`native-layout.js` 和 `commander-workflows.js` 未给该列表或物品按钮接通教程标记。
3. UI框修正量没有应用。脚本给资源栏 `w=-90,h=0`，其他按钮有 `w=-4,h=-4`、关闭按钮 `w=-24,h=-22`。`positionTutorial()` 的UI分支直接使用DOM外框，没有读取这些修正量，也没有区分原生列表容器与指定行。
4. 显示尺寸固定。高清指示手PNG为70×94像素，当前CSS放进22×24像素容器并contain，不保持原资源比例对应的逻辑尺寸，也不随战场UI倍率变化。该点是实现偏差；本轮未测出原版构造函数中尺寸常量，不能据此给出精确替代尺寸。
