# r版 PixiJS 与已知性能问题实施记录

2026-10-23。本轮实现与本地验收完成，手机真机性能待验。本会话用户明确要求按审计及断点接入 PixiJS 并优化已知问题，取代旧报告的实施暂停边界。没有修改发行版本、打新 APK 或发布。

## 路线与范围

- 战场动态精灵、BILE 姿态、兵牌、旗帜及最终合成由离线 PixiJS 7.4.3/WebGL 批绘；官方 CSP 模块避免放宽原内容安全策略，不依赖 CDN 或 WebGPU。
- 静态地图块、文字、少量复用染色素材以及菜单继续使用 Canvas 2D。保留原资产与动画解析，不把所有 Canvas 使用都当作问题。
- 地图改为有像素预算的 512 地图坐标块，按实际地块/相邻外溢、颜色和图片依赖失效；海岸/边界栅格化去除逐像素临时数组，载入时分时预热当前区域及远景范围。
- 远景在姿态计算前切换兵牌，0.52/0.62 滞回，保留真实位移、血量、将领与状态。活动动画由唯一 rAF 驱动，撤销原 30Hz 上限，静态/遮挡仍按需绘制。
- 普通和快进统一地块、单位更新/删除/顺序及 baseRevision；完整开局、读取和失步同步保留。移动执行结果携带原始路径，避免展示再求一次同路线。
- 同步 AI 规划内按对象身份复用校验，调用结束释放，脚本/扩展不进入信任路径。移动候选复用可达结果，内置候选保留完整领土、事件、胜负模拟，但共享未变对象；公开实际执行仍深复制、校验。
- 战略目标落点用局部六角邻域，必要连通性过滤保守处理有向边，距离场按当前通行条件最多缓存 8 份；调度保留格号/ID 顺序并过滤无请求单位，不跨提交保留旧队列。
- 存档直接写入已编码世界，消除世界 JSON DOM 的解析/再编码与多余校验；槽文件流式序列化。保留兼容版本、校验和、每势力保存边界、Flush(true) 和原子替换，没有后台写队列或删存档边界。
