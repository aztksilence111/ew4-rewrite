# R 核心空地分层 Mod 接口

2026-11-02，源码实现，尚未打包发布。现有 0.2.30 发行包不含此接口。

## 交付边界

- R 本体默认关闭，保持原有整格容量、移动、攻击及存档行为，不提供航空开关或航空兵种。
- Mod 使用 API 3 的 `unitLayers` 配置入口并显式 `enabled:true` 启用。支持地表与空层同格，各层独立容量、阵营约束及普通攻击/反击目标层。
- 招募、事件、召唤/传送、移动/撤回、战斗、溅射、AI、存档及选择接口接入分层。飞机不占地，不阻挡地面，不参与地面包围，不继承地表建筑/地形防御及原地面邻格将领光环。
- 按用户补充，删除底部分层工具按钮；仅在部队属性说明区显示“作战层：空中/地表”。首次点格优先地表，重复点格轮换；合法攻击优先，多目标时选择实际单位。飞机绘制和标记向右上偏移。
- 旧模板类别仍决定原有伤害表、科技与将领兵种星级；没有新增独立航空能力。范围技能/Lua 不自动受到普通攻击目标层约束。
- 未实现具体航空兵种、终身一次运输投送、近支专用光环、侦察情报或建筑本体损毁。具体范围及配置见 [接口说明](../rewrite/mod-kit/docs/porting/UNIT_LAYERS.md) 和 [最小示例](../rewrite/mod-kit/examples/unit-layers/README.md)。
