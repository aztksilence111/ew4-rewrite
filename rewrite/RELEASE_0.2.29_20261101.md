# 0.2.29（2026-11-01）

Android ARM64 APK 与 Windows x64 独立 Web 版，规则 API3。

- 修复重炮等部队第一步无法进入高于剩余移动预算的山地，同步导航、AI 路线和站位判断。
- 修复栅栏、战壕、掩体的减伤提示，地形与工事按对应兵种取实际较大值。
- 修复城市升级金框：本体最多升六级，初始七级保留；Mod 可通过 maxlevel 配置升级上限。
- 交易窗口原地更新资源及按钮，减少连续交易卡顿和闪屏，并防止并发提交。
- 新增通用事件增援、任命、卸任、和平撤编接口，支持既有国家或建国同批使用，保留伤兵比例及存档记录。
- 东亚底图纳入岛屿海陆修正、塔城位置微调及五处新增城市；不附带民国 Mod、规划、剧本染色、辖区或事件。
- Android 与 Windows Web 主菜单、对局暂停设定均保留完整存档导出。

Android 沿用原包名与签名，versionCode 32。Windows 解压后运行 Start-Web.cmd。
