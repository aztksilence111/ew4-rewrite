# 通用禁行地形实施记录

2026-10-25，用户授权“可以修改了”后完成。两类能力均为 rewrite 全局及任意 Mod 可复用接口。

## 实施结果

- 新增 `TerrainBarrier.None/Mountain/Ocean`。统一通行判定先于技能、行动力、运输、河流、桥梁和超额进入；覆盖路径提交、AI距离场与连通分量。
- 禁行格保留可见和可点选，不允许部队、城市、设施、工事、目标、领土或辖区传播；招募、部署、召唤和传送落点受同一限制。
- API 3 的 `rewrite/extension.json.geography` 引用逐图 `geography.json`，校验注册名、宽高、基础 BIN SHA256、坐标、海陆及实体冲突，支持名称和图集精灵替换。
- `geography-template` 命令生成作者模板。双地图示例实测欧洲和东亚均可同时使用两类地块，导入、真实开局、导出重导入及规则指纹变化通过。
- 六种原版派生增高积雪山、一种深色海洋，普通/高清各7个新精灵。按用户最新参考图恢复初版的小范围柔和积雪、原岩面明暗，仅将积雪色调由RGB(225,237,242)微调为(238,244,247)；不再使用大面积折线雪盖与加深裸岩。已有每套76个图集精灵像素不变；Canvas/Pixi均绘制新图层并替换原山地覆盖层。
- 世界存档写版本5，读4/5；含禁行属性的现代地图写版本2，普通图仍写1。缺省属性不改变原有序列化形状；地理修改参与规则指纹，不静默迁移旧战局。

接口：[作者指南](mod-kit/docs/porting/GEOGRAPHY.md)，示例：[覆盖包](mod-kit/examples/impassable-geography/README.md)。

## 当前东亚

按用户后续意见，三条山口的7个越脊格显式设为 `mountain_pass`：使用原版山地贴图和原版地形信息显示，不增加“山口”或“山地”文字；保留山地防御、移动成本6及最低进入成本6，步兵/地理技能也不会按平地消耗通过。中央开口原来有一格平地，现已修正；两侧进出河谷保持原地形。两类禁行格的默认提示统一改为“不可通行”。

山口辨识调整：固定选用原版 `mountain_1.png` 单峰岩面，绘制高度降低15%。邻接山口的默认禁行雪山仅缩窄10%、向外偏移最多6地图像素，形成鞍部并减少遮挡；沿用用户确认的柔和积雪，不增加道路、名称或新材质。

当前158×136图新增121格禁行雪山。保留三条连续通道：普兰—里普列克、吉隆／聂拉木方向概化合并、亚东—乃堆拉／则里拉概化合并。格距约42公里，合并路线不表示现实同一条道路。

山口通道均验证六邻接连续；局部重新封闭其开放格后，指定走廊两端失去连通，未发生局部漏穿。山脉两端仍可按实际地图绕行。山脊为概化折线及42公里半宽，不是精确高程数据；史地依据为初步百科资料，不代表所有时代的重装备通行能力。

四国岛新增高知2级城，落格(129,72)，格号11505、城市ID10278，距真实位置约30.67公里。沿用现有约42公里格距，落在岛内可见陆地上；该格从山地转为常规城市陆地。原278座城市的编号、落点和记录保持，总城市数279；272处设施、54座桥梁保持。配置、检查剧本和现代可复用模板同步；两种城市语言为“高知”／“Kochi”。

新增城市通过 `build_eastasia_runtime.py --additions-only` 追加，`integrate_eastasia_builtin.py --cities-only` 合入内置资源；这两个入口复用已确认的底图与地理标注，避免旧生成目录覆盖当前文字布局。[追加校验](../maps/eastasia_rewrite/city-additions-verification.json)记录唯一变化的原始地形格及已有城市/设施保持结果。
