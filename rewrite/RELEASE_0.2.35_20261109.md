# 0.2.35 — 整编操作、音乐接口与 AI 优化

Android ARM64＋x64 通用 APK（versionCode 38），独立 Windows x64 Web，规则 API 3。

- 修复整编窗口将领列表拖动与触屏横滑，选择将领、取消确认后保留滚动位置，避免滑动误选。
- Mod 可配置自定义 BGM 列表、顺序轮播、指定剧本及胜负音乐，替换原音效、添加音效别名或静音；附最小源码示例与格式说明。
- AI 在同等价值据点之间优先考虑距离，修复远角目标过度优先；优化分层部队目标检索。
- 触屏动画待机按30帧、移动／战斗等活动按60帧调度，输入和状态变化即时刷新。
- 新增独立 Windows x64 作者工具包：自带运行环境、完整基础资源、中文双击检查／导出入口、接口文档和命令源码。作者修改工程后重新生成清单与规则指纹，通过完整校验后导出 `.ew4mod`。

双端保留主菜单与对局暂停设定中的存档ZIP导出／导入、Mod高星能力与既有规则接口。Android保持原应用ID和签名，可直接覆盖安装；请勿卸载或清除数据。Windows完整解压后运行 `Start-Web.cmd`。

作者工具包请完整解压，阅读根目录 `README.zh-CN.md`；修改 `project/`，依次双击 `01-check-project.cmd` 和 `02-build-mod.cmd`，成品在 `exports/`。本包适配0.2.35；其他版本须先核对兼容性。仅修改清单里的哈希不能修复错误资源。

附件包括Android APK、Windows Web ZIP、作者工具ZIP、`SHA256SUMS.txt` 和 `release-manifest.json`。性能验证采用本机合成场景及触屏模拟，不代表手机实际温度或功耗；没有ARM64实体手机实测。
