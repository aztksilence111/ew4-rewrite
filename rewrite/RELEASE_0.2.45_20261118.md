# R版 0.2.45

- 装备支持同一ID反复购买，取消同种物品约四件的限制；相同属性的原版副本合并显示数量，旧ID、旧存档和Mod资源继承继续兼容，独立配置的Mod物品保留各自行为。
- 设定中的“将领头像”下新增“物品贴图／物品图库”，支持PNG、JPG、WebP上传，透明等比缩放、位置调整及恢复当前原版或Mod默认贴图。商店、背包与装备图片即时同步，上传内容随存档导入导出。
- 头像图库支持当前将领恢复默认；Mod皮肤使用独立竖图轮播，拖动跟手、短拖回弹，确认后应用。原版或未配置皮肤的将领隐藏皮肤入口。
- 修正设定入口排列及两个图库关闭按钮遮挡顶栏花纹的问题，覆盖桌面和手机横竖屏。
- 作者工具包更新至1.1.11，与本版运行库一致；包含JSON路径指南、独立APK原证书签名工具及皮肤接口说明。更新时保留自己的project、exports、_work和Mod原始资源。

Android包包含ARM64与x64，沿用原发行签名；Windows Web包可独立运行。账户、各存档槽及备份可从主菜单或暂停设定导出。未进行本轮Android真机交互验收。
