# 裁出得抚岛后的日本全图参考

2026-10-25。依据用户红圈，只裁出最东北侧的得抚岛，不抹除岛屿或涂成海洋。得抚岛位于择捉岛东北，不属于北方四岛；旧参考框实际额外包含了它。择捉、国后、色丹、齿舞及完整琉球参考范围继续保留。

![新15°/20°/25°对照](japan_angle_comparison.jpg)

| 方案 | 顺时针旋转 | 参考画幅 | 相对最初J1全幅的面积减少 |
| --- | --- | --- | --- |
| D | 15° | 1632×1124 | 16.2% |
| E（当前建议） | 20° | 1707×1033 | 19.4% |
| F | 25° | 1770×934 | 24.5% |

推荐维持20°：保留用户此前认可的斜向，裁掉得抚岛并收紧边缘后即可减少空海，无需增加到30°。上述数值是画幅面积变化，不是海洋占比；新20°画幅较旧20°进一步减少约9.4%。
