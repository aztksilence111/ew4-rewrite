# 0.2.17：性能优化、旧版 WebView 兼容与移动界面修复

2026-10-23。Windows x64 独立 Web 包与 Android ARM64 APK（版本码 20），规则 API 2，沿用既有 Android 签名。源码提交、包大小和 SHA-256 见附件 release-manifest.json 与 SHA256SUMS.txt。

- 战场接入离线 PixiJS 7.4.3 / WebGL，支持失败时回退 Canvas；优化地图分块、预热、远景兵牌、动画调度、AI 规划复用、增量传输及存档写入。
- Web 与 Android 共用 Chromium 70 兼容构建，补齐旧版 WebView 的接口、图片解码和布局兼容。
- 统一手机和平板布局，修正挖孔区域导致的整屏留白、四角按钮贴边、暂停及设置遮罩、菜单灰边和远景兵牌；保留城市名并改善血条绘制。
- 默认自动完整快进过回合；关闭自动选项后可用左下按钮手动完整快进。
- 复用顶部资源图标与数字节点，减少点击时的重复创建和重绘；伤害数字恢复原版位图。
- 修复掩体、战壕、栅栏建造窗口的图片、说明、默认选中和真实费用报价。
- 修复军事学院满额购买报错；Mod 可分别设置三个星级区的将领上限。
- 本机 Web 预览默认静音，可在设置中手动开启。发行包不包含玩家账户或存档。

构建、专项回归、发行包资源及签名核验见[发布进度](https://github.com/aztksilence111/ew4-rewrite/blob/main/rewrite/RELEASE_PROGRESS_0.2.17_20261023.md)。Android 真机性能、冷远景长帧和未定位的整屏闪动仍需实机复测；桌面验证不能替代真机结果。
