# R 版友方领土运输船改造修复

运输船改造原先复用了仅允许本国领土的购买校验，导致本方陆军在友方领土上没有改造入口，直接提交也会被拒绝。

`WorldSupportActions` 现仅对运输船改造允许本国及当前同盟领土，使用 `WorldDiplomacy.Allied` 识别同阵营默认关系和外交覆盖。报价、按钮可用性、实际购买及 AI 共用该规则；部队仍须归当前行动方所有。敌对、中立、无主领土以及兵种、地形、资金限制继续生效。设施建造仍要求本国领土。

回归覆盖友方报价、实际改造、只扣本方资源、不占领友方土地、保留移动力、输入不变、存读档、资金不足、外交覆盖及客户端入口／完成后防重复购买。新增客户端用例先在修复前复现失败，修复后通过。

- 单项客户端 191、建筑改进 8767、支援操作 7546，共 16504 项，错误 0。
- 验证程序、Windows Web Compile、Android ARM64 Compile 均零警告、零错误；Android 使用项目既有独立 SDK 工具链。
- 未打新 APK、正式发行或更新玩家运行目录；未做 Android 真机验收。

本轮临时编译和测试账户清理凭据：`build/maintenance-20261109/allied-transport-cleanup.json`。源码测试保留，原账户、存档、已安装 Mod 和同期修改保持。
