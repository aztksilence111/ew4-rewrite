# 0.2.15

- 剩余部队定位改为三个白色六边形，移到右下沙漏上方，增加剩余数量角标。
- 定位排除没有合法移动落点和攻击目标的部队，包含无目标要塞、被围部队和移动耗尽后无目标部队；数量和定位使用同一筛选结果。
- 修正侧边按钮的阴影、主体对齐和透明区域误点击，保持暂停键可见尺寸。
- 修正界面字体外观：内置传统楷体中文、粗衬线英文及普通数字、粗黑斜体战斗数字；地图原图层与既有中文显示链保持。
- 默认显示隐藏战役，恢复双国家分支的原版选择界面，并支持 Mod 配置战役可见性。
- 接入原版背景音乐及音量控制，支持主菜单、战斗和失败场景切换，并支持 Mod 替换音乐。

Windows Web 包自带运行时，解压后运行 `Start-Web.cmd`。Android 附件为 ARM64 APK，版本0.2.15、versionCode18，沿用旧版签名证书。

不包含玩家存档。两平台共享游戏逻辑与前端；附件包含校验清单和源码提交标识。Android 真机运行、最终字体外观及触控体验仍需实际设备复验。性能优化规划与点击闪烁专项保留后续任务状态，本次不宣称已解决。
