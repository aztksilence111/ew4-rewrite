# 欧陆战争4 重构 0.2.44

设定新增“将领头像图库”，支持按姓名、编号、阵营搜索，按阵营、招募星区、拥有情况及上传/皮肤状态筛选和排序。可直接上传有权使用的PNG、JPG/JPEG或WebP图片，在游戏内裁剪和调整取景，同步替换将领立绘及局内圆形小头像；支持恢复原始头像、复用和移除上传。

上传入口明确注明要求：单张不超过10 MiB，最长边不超过4096像素，建议至少512×512。每个档案图库最多64 MiB，原版与Mod档案隔离，图片随存档导出/导入保留，不需要修改安装包。

新增API 3将领皮肤接口与最小源码示例。Mod可用任务、成就或内部目标解锁皮肤，按优先级自动切换；玩家在指挥部将领详情“皮肤”入口手动选择，或恢复跟随剧情。仅修改皮肤清单及图片不改变逻辑存档身份。

包含0.2.43整编界面修复、原版获得将领窗口补全，以及Mod制作过程中补齐的通用指令、目标和呈现能力。发行包不包含民国Mod、测试档案或玩家资料。

Android通用APK（ARM64＋x64，版本代码47）、Windows x64 Web，配套作者工具包1.1.9；规则API 3，沿用原发行签名。主菜单和暂停设定保留存档导出。本次无Android真机交互验收。
