后续配色接口已补齐：国家与新增势力沿用现有 `color`，阵营地图新增 API 3 `mapColors`，支持指定 camp、色池及逐剧本覆盖。见[实现与验证](MAP_COLORS_20261025.md)、[作者指南](mod-kit/docs/porting/MAP_COLORS.md)。默认配色和自动字母保持原样。

## 最终行为

- 暂停左侧新增地图键，沿用原版暂停键材质及尺寸，间隔为6个CSS像素。
- 默认普通地图，点击后向下展开其余两种地图，切换后收起；三种模式互斥。
- 底部居中的三角随展开旋转向上；展开、收起都有位移和透明度动画。
- 辖区图标为左侧两个空心六边形、右侧一个实心六边形。
- 阵营地图按真实camp分组着色，不以玩家的双边敌友关系代替阵营。配色池循环使用，避免随阵营数无限增加颜色。
- 阵营采用唯一字母缩写，需要时扩展为多字母。原剧本按最早原阵营成员确定默认名称，法国所属阵营为F；未新增剧本作者配置阵营名的接口。
- 阵营缩写直接叠在近景兵牌圆面内部、兵种图标右下角，透明底银色金属字，无城市旁黑底块。
- 缩至原有badgeOnly远景时不请求或绘制新增阵营缩写；原版兵牌、血量圈及将领头像保持。三个地图模式均遵守这一规则。
- 辖区地图使用实际jurisdictionCenter，在同国辖区之间画深灰圆头短虚线；原国界和海岸仍使用原有绘制。
- 显示切换只改变渲染，不改归属、外交、回合或存档数据；新开局/载入恢复普通地图。

- `Ew4.Web/wwwroot/map-views.js`：阵营投影、缩写与下拉控件。

- `Ew4.Web/wwwroot/battlefield.js`：阵营色、辖区线、金属字以及远景隐藏。

- `tools/build_map_view_icons.py`：从原暂停贴图生成三张按钮材质。
- `tools/verify_map_views.cjs`：实际Canvas/Pixi浏览器回归。

兼容前端必须通过`node tools/frontend/build.cjs`重新生成；服务实际读取compat版本。
