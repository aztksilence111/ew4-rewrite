# 0.2.20：地图、教程、指挥部与回合优化

2026-10-25。Windows x64 独立 Web 包与 Android ARM64 APK（版本码 23），规则 API 3，沿用既有 Android 签名。精确源码、大小和 SHA-256 见随包清单。

同日修订沿用 0.2.20 / 23 并替换原附件：移除暂停回合下的测试序列，征服与战役补回自带字库渲染的“载入”，修正适配后的章节图标及弹出框位置。

- 优化过回合规划、校验、辖区查询及内存分配；大地图使用原始地形图的 GPU 缓存，按需加载兵模和地图名称。
- 修复占城后外军驻扎格归属、自动辖区孤立碎片及空港旗帜；恢复原版挑衅外交，战役本地多人支持中立国并按交战状态加入阵营。
- 补齐战役桥梁显示、教程指示手和地图箭头动画，修正确认键、费用提示、上将名册及军事学院居中。
- 新增普通、阵营、辖区地图视图，以及暂停目标栏，展示实际胜负条件和星级回合范围，支持手机布局及滚动。
- 指挥部新增任务、成就及筛选接口，支持 Mod 配置奖励；R 版默认不预设任务条目。
- 东亚补充曲线中英文地名、河流河口、雪山山口与高知城市；通用禁行地形、地图配色和文字路径向 Mod 开放。
- 规则目录拆为独立 JSON，保留旧资源导入兼容，Web 包附作者指南和示例。

发行包不包含玩家账户或存档。桌面及浏览器自动检查与 APK 内容、程序集、签名和 16KiB 对齐检查见发布记录；手机实际运行和性能仍待真机复测。历史性能比较只对应各自测试场景，不代表所有地图均达到相同耗时。

构建记录见[发布进度](https://github.com/aztksilence111/ew4-rewrite/blob/main/rewrite/RELEASE_PROGRESS_0.2.20_20261025.md)。
