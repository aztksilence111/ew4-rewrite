# 0.2.39：独立兵种 Mod 接口

- API 3 新增可选 `unitRecruitment` 配置。作者可新增独立字符串 ID 的兵种，与原兵种同时存在、单独显示和招募。
- 支持自己的属性、兵模/卡图、建筑种类、最低等级、三资源价格、国家及剧本范围；原兵种报价保留。
- 海军可在海面港口招募，AI 使用海军生产组；后续创建的势力也能按国家范围获得招募权限。
- 新兵种及招募授权随存档保存；开局增援可通过 `unit_spawn` 引用新 ID，传统 BTL 数字槽仍保持 0～21。
- 提供完整接口说明及可从作者基础数据生成步兵和舰船的最小示例；配套 EW4 Mod Editor 0.4.2 提供“内容编辑 → 兵种”入口。

Android 0.2.39 / versionCode 42，ARM64＋x64 通用 APK，沿用原签名。Windows Web 解压后运行 Start-Web.cmd。规则 API 3，配套作者工具包 1.1.4 同步运行库。

本版基于已发布 0.2.38，保留将领换装、消耗品数值及存档导出等既有功能。自动化测试与封包检查结果见发布验证记录；未进行 Android 真机验收。
