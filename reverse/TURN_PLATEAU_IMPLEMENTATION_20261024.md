## 已实现

| 项目 | 实现及边界 |
| --- | --- |
| 兵模绘制 | 将缓存姿态中的图块仿射变换预先展开，直接提交给 Pixi；复用提交矩阵，减少每帧每图块的 DOMMatrix 复制、栈数组与矩阵构造。Canvas 回退继续原接口。 |
| 镜头交互 | 有限地图缓存增加周边预热；拖动/缩放后 120ms 内暂停后台建块，随后恢复。仍保留 12Mi 像素地图缓存上限。 |
| 通用空间查询 | 地图装饰、地图片、文字和部队按空间分桶，查询视野后按原顺序绘制；超大包围盒单独保留，避免向大量桶复制。目标地块集合随实际地块变化更新，移动中的目标和部队继续参与显示。 |
| 冷区域绘制 | 拖动、缩放、部队移动或招募动画中遇到缺块时，先以最多 256Ki 像素的共享底图绘制陆海底色及领地，复用已有完整地图块；不在这些交互帧解码陌生地图图片。交互及动画结束后空闲任务逐块补齐地形，逐个生成和上传新城市名称。临时地形会较简略，部队、兵牌和选择持续绘制。完整地图块仍为 12Mi 像素，极大视野按投影缩减栅格密度。 |
| Pixi 对象 | 每个绘图槽按需创建 Sprite 或 Graphics，闲置尾部从场景树脱离，保留池供下次复用；避免每个图块同时常驻两种对象及每帧重排全部对象。 |
| 兵模加载 | 状态更新只等待视野周边和移动/战斗参与者的兵模库。镜头新遇到的库异步去重加载，先保留兵牌，完成后重绘；不再等待全图场外所有兵模。已有 1024 姿态上限和 GPU 纹理预算继续保留，这不是对任意未来素材体积的真机内存认证。 |
| 批次一 | 新增内部受限反向 Dijkstra，起点最短距离出队即停止；只返回已确定的需求距离，严格更近的落点均已确定。工作距离数组及堆临时租借，结果独立持有；完整距离场接口不变。每个运输分支的可达格只排序一次。 |
| 批次二 | 在领地和辖区实际写入位置记录归属；封闭的 OwnershipBuffer 只允许改 Owner，封存后不可再写。最终集合去重、剔除恢复原值、按格号排序。通知、原领主提取与候选校验消费集合，真实提交仍完整校验。辖区转移、农田连锁、盟友保护均覆盖。 |
| 批次三 | 同一同步作用域内按实际世界身份复用势力、单位ID、驻军、目标归属索引，以及按规则身份隔离的单位/位置/目标事实。移动基础格与外交视角按行动者归属隔离；禁用子树清除外层证明和查询。作用域结束释放，不跨回合缓存。 |
| 批次四 | 内部候选顶层地块和单位集合封为只读，未改变嵌套数据仅在同步内借用；候选占领事件没有实际写入且历史规范化结果相同才省去深复制。事件确实触发即先复制，公开动作与 WorldState.Copy 的独立所有权保持。 |

没有削减 AI 目标、玩法步骤、事件、对白、历史、保存或 flush。已实现的保存编码缓冲继续保留，本次检查未发现需要再次改写的重复物化。AOT 继续作为独立可选实验，默认模式保持 JIT；不扩大低命中距离缓存。
