## 修改

- ClientGame 按格索引攻击目标，缓存敌方集合；大射程仍回退全军扫描。新募部队检测使用 ID 集合。
- 回合结算使用本轮私有部队数组、格索引、占位集合与相邻将领索引。死亡事件后重建索引，保留死亡、投降、领土和士气结算顺序，输入快照不变。
- 扩展状态过期只生成一次部队数组；事件通知按 ID 比较。回合事件跳过无绑定的空调用，实际技能改变部队后刷新索引，继续按原顺序触发。
- 前端按集合比较新旧部队，消除普通状态安装和战斗阵亡检测中的平方扫描。
- 远景合成原版血条、血量环和兵种标记，保留逐层闪烁透明效果、固定屏幕尺寸、将领标记及近景显示。AI 标记与死亡表现使用原路径。
- 标记缓存最多 128 项 / 2097152 像素；每帧最多新建 8 项 / 262144 像素，单次出现的组合走原绘制，防止大量不同血量导致缓存反复生成。素材修订或图集更换后失效。

## 验证与边界

- 供粮 / 生产 / 回合 / 生命周期 20619 项；败国 / 回合 / 入场 / 环境阵亡 / 战斗 14183 项；扩展 229 项；客户端 64518、海军部署 24 项通过。
- 压力浏览器 8 组：双渲染、桌面 / 手机横屏、1 / 0.3 / 0.09 缩放；均为一万支部队，拖动和滚轮缩放通过，画布像素非空，无脚本异常。
- 合成 / 原绘制像素平均通道差小于 1.55 / 255；不同血量 1000 组检查确认每帧最多生成 8 项。五视口既有回归 312 项通过，资源错误 0。
- Web / Android Compile 零警告错误；Chrome70 前端 50 文件检查通过。
- 旧性能套件的 `Session encoding changed authenticated bytes` 和旧界面套件的 `drag and wheel cannot override locked camera` 在优化前基线同样失败；未修改相关存档格式或镜头规则，不将两套件报告为通过。
- 首次完整状态仍约 34 MB；完整一万部队 AI 回合、Android 真机帧率 / 内存 / 发热未验收。极远景的软件 GPU 和冷贴图峰值仍可能卡顿，不宣称稳定 60 FPS。
