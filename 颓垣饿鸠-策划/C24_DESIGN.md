## 1. 范围与已接受原则

- 开局沿用1924年9月15日；体验集中于第二次直奉战争、同期江浙战争、广州商团危机及北京政变的直接后果。
- 历史参照范围暂收束到1924年11月北方善后及临时执政就任前后。它是事件取舍边界，不是强制玩家重演全部历史或到日期自动结束的脚本。
- 用户已同意先形成开局关系表、主要转向事件和分势力阶段目标，再讨论修改，之后才进入游戏内容制作。
- 用户要求以本剧本的玩家体验和当时节点还原为准。因此不制作后续奉冯战争、郭松龄反奉、第一次东征、杨刘事变、滇桂战争及孙中山逝世。这些不作为隐藏的必触发续篇。
- 冯部开局仍属直系体系，但冯与曹吴的矛盾及反直联络已有历史背景。按用户最新意见，直系首次夺取奉系城市，或奉系首次夺取直系城市时，即开启脱离直系事件；电脑冯部自动转向，玩家冯部选择是否转向。事件说明体现其政治主张、本部利益、内外联络与战时机会，不能写成临时起意。独立国民军阵营及政变后的具体关系仍为本稿提案。
- 历史日期与游戏回合分开登记。冯部转向取消固定回合门槛和回合兜底，改由首次夺城的实际战况触发；这是用户确定的玩法条件，不宣称历史上冯以“首座城市失守”为行动标准。
- 地图继续使用用户提供的史图馆截图作版图参考；月份画面不能直接证明9月15日逐城控制。暂不另搜视频。
- 用户新增共通规则：所有可选势力完成本方阶段目标后，均可通过事件选择统一全中国，含地方及外国势力，不因初始阵营或规模排除。1924年范围限定的是历史事件编排；主动选择统一后可在当前战局继续架空征服，不因此补入1925年及以后的历史事件链。
- 用户补充统一顺序：阶段目标完成并选择续战后，先消灭敌对阵营，盟友暂缓；敌对阵营清除后，再通过事件决定是否与盟友开战，不在统一路线开启时自动解除全部同盟。
- 用户明确两次决策都是结局分支：阶段目标完成后不继续即进入阶段胜利结局；清敌后维持同盟即进入联盟胜利结局；只有选择继续才保留当前战局，最终统一后进入统一胜利结局。
- 用户确定全国目标只按“秋叶海棠”地理范围，东亚底图其他地区只作外部干预。边界和各结局判定统一遵守[UNIFICATION_BOUNDARIES.md](UNIFICATION_BOUNDARIES.md)；清敌不要求境外势力在全图出局。

### 4.1 冯部为什么转向：历史背景与呈现

政变动机有多个层次，不宜用“厌恶曹锟”“吴佩孚战败”或“受到收买”中的单独一项解释全部过程。

| 层次 | 历史背景的稳妥表述 | 本剧本如何表达 |
| --- | --- | --- |
| 派系与本部利益 | 冯并非吴的嫡系，与吴长期存在兵权、地盘、待遇及发展空间的矛盾；胡景翼、孙岳也有自身不满和政治联系 | 开局简报交代冯部虽属直系却有独立利益；保全部队、摆脱曹吴支配成为转向的现实动机，不凭空给一项“忠诚度归零”规则 |
| 政治主张 | 曹锟贿选损害中央政治声望，冯以反对内战、倒曹罢吴及拥护孙中山等主张争取政治正当性；这些主张与争取自身地位并存 | 军议同时呈现政治诉求和势力利益，不写成纯粹为公或纯粹私人报复，也不称其此时已经完成后来的政治转变 |
| 事前联络 | 冯与孙中山方面、奉方及段祺瑞方面存在联络；胡景翼和在京的孙岳是政变的重要合作者 | 开局用一段背景说明已有接触，行动军议再交代接应；不要求玩家从零攒外交好感，也不把所有接触都等同永久军事同盟 |
| 战争与行动机会 | 第二次直奉战争使吴的主力集中于前线，冯部具备回师条件，京内接应使控制中央成为可行计划；给养及作战压力也加深对继续替曹吴作战的疑虑 | 以直奉之间首次夺城作为游戏行动窗口，区分直系推进和奉系推进两种军情；不把单城得失写成全线胜败，也不强制冯部自身先打输 |

历史上的“为什么要动手”与游戏中的“何时给玩家决策”分开处理。先有派系矛盾、政治诉求和合作准备，战争提供机会；首次夺城是本Mod的玩法触发条件，不能据此倒推历史政治动机。

呈现过程控制在必要节点：开局本方简报交代分歧与秘密接触；直奉任一方首次夺取对方城市时出现一次关键军议；选择后执行E04外交切换；实际取得北京后才执行E05成功通知。不增设一串无实际作用的前置弹窗。

军议标题拟为“回师北京”。正文基础稿如下，为游戏改写，不冒充冯玉祥原话、史实电文或逐字会议记录：

> 曹吴掌握中央，我部虽列直军，却始终难以自主。继续随军作战，既要承担前线消耗，也难改变受制于人的处境。此前与反直各方的接触已有回应，孙岳、胡景翼亦可相应。与其继续这场内战，是否回师北京，倒曹罢吴，再议国事？

这段正文只能在有关合作力量仍有效时完整使用；内应失效、北京易手或战局不同，就改为符合当前状态的版本，不能声称已经战死的将领仍在接应。前线实际胶着时可加“吴部主力正与奉军相持”，不能一律写“吴军已溃败、北京空虚”。

正文按触发方向增加以下军情开头，为玩法改写而非史实引文：

- 直系夺取奉系首城：“直军已夺取奉方一城。曹吴若借此继续坐大，我部仍难摆脱其控制。双方主力既已投入争夺，此时是否利用已有联络，回师北京，另立局面？”动机侧重趁战争进行、争取自主，不声称直系已经胜利。
- 奉系夺取直系首城：“奉军已夺取直方一城，前线压力加重。继续替曹吴作战，我部仍要承担消耗。此时是否利用已有联络，回师北京，倒曹罢吴？”动机侧重摆脱消耗、改变局面，不声称全线崩溃或曹吴已无反击能力。

两种军情共用相同选择和外交结果，避免为一次转向再拆出不必要的路线。

| 按钮 | 玩家决策含义 | 明示后果 |
| --- | --- | --- |
| 回师北京，倒曹罢吴 | 利用已有联络争取独立地位，以停止内战及改组中央为政治主张 | 与曹吴决裂、改国民军阵营、按E04调整关系；夺京仍需实际军事行动，不保证政变成功 |
| 暂弃倒曹，继续对奉作战 | 在本局选择继续维持直系作战合作，承担继续战争的风险 | 本局不再自动发动政变，仍需完成冯部对奉作战目标；不附送不存在的曹吴封赏，也不宣称冯因此成为吴的嫡系 |

孙岳的京内身份、胡景翼的独立部队须在初始部署中落实。不能因为人物后来参加国民军，就把所有相关单位开局全划给冯部；若采用内应转属，只转移明确标识且仍存在的合作部队，不无条件接收北京其他守军或玩家后来调入的军队。若最终不单设内应单位，军议只表述为政治接触，不能承诺部队接管效果。

### 4.2 首次夺城的判定口径

按用户最新意见，取消定回合触发，只保留AI默认转向、玩家可拒绝的处理。初稿采用以下口径，供后续修改：

- “直系”计Z/F/Q/S这些中国军事势力，包含尚未脱离的冯部；不把同营英国算作直系夺城者。“奉系”计T，不把浙江卢部或其他反直合作者等同奉系。
- “对方城市”以开局实际归属登记：直系夺取开局奉系城市，或奉系夺取开局直系城市。计城市及首都，不计农田、港口、工厂、马厩或普通地块；具体城市格待地图确定。
- 必须是新局开始后的实际敌对夺城。开局已有版图、收复己方开局城市、盟友间转交及剧情划地不计入，江浙双方单独夺城也不误触发。
- 首个符合条件的夺城完成后检查并锁定方向，两个方向先发生哪个就使用哪个军情版本；保存待选状态及最终决定，后续夺城、换手或读档不再次询问。
- 任一方向符合即触发，不要求双方各夺一城，不加最低回合数，也不加“无人夺城到某回合自动触发”。无人达成则不发生此次事件。
- 冯部已出局、已作出选择或北方战争已结束时按既有跳过规则处理；拒绝后即使出现反方向夺城，也不再次迫使玩家决定。

本节只定义策划判定，不生成事件JSON或Lua。实现讨论时应按具体城市及夺城记录判断，不能用总城市数增加替代，否则攻占第三方城市也会误触发。

史料参考与使用范围（2026-10-21查阅）：

- [北京政变条目](https://baike.baidu.com/item/北京政变/1078005)：用于核对总体过程、派系矛盾及反直联络的线索，是汇编材料，不直接把每项细节当作已核实史实。
- [《揭秘北京政变始末：孙岳夫人与曹锟打牌作内线》](https://www.chinanews.com/cul/2011/11-02/3431477.shtml)，中新网转载《兰州日报》，2011-11-02，孙华岑、孙华嵘撰：用于交叉参考孙、冯、胡的合作、前线任务与京内接应。作者为孙岳后人，文章含回顾性评价及戏剧化对话；对“吴有意消耗冯军”等表述按当事方判断理解，不当作无争议事实，不照搬其对话。文章开头10月24日与后文23日的日期表述不一致，本稿不据此变更政变通行日期。
- 涉及日方资金、具体金额、秘密承诺与每次联络日期，仍需进一步史料核对；本版不把争议细节设置为必经原因，也不虚构一笔收款后立即倒戈。

## 5. 分势力阶段目标

“阶段目标”首先决定玩家为何作战，不是已经写死的胜利数值。持续回合、所需城市和兵力门槛均待地图落实；不强制所有地方势力消灭全地图。所有势力在达标后均可主动选择统一全中国，阶段目标不限制其后续发展上限。不能仅因一方被盟友消灭就无条件给另一方完成夺城目标。

| 玩家势力 | 本局主要目标 | 阶段完成条件方向 |
| --- | --- | --- |
| 曹吴中央 Z | 击退奉军、维持中央与京津交通 | 主战线取得优势；发生政变时保住或夺回京畿核心，并保存本方主力 |
| 冯部 F：转向 | 保存主力、控制北京、建立独立地位 | 北京确实在本方控制下，国民军存续并保持核心控制达到约定轮数 |
| 冯部 F：不转向 | 完成直系战场任务且保有自身军力 | 与奉方作战取得本方战果；不能只靠曹吴盟友胜利、自己全程不行动过关 |
| 奉系 T | 突破关内门户，取得北方战争主导权 | 关口及关内关键节点的实际战果，削弱曹吴中央；无需消灭全部南方地方势力 |
| 浙江卢部 L | 保住浙江淞沪立足点 | 核心据点、残存兵力与持续防守；失去据点后可有保全残军的较低阶段评价，不能冒充完整胜利 |
| 齐部 Q | 保住江苏并争取淞沪 | 本方直接控制指定江浙目标，主力存续；不以占北京为必要条件 |
| 孙部 S | 突破浙江方向，巩固闽浙地位 | 指定目标及本方控制范围达到门槛，不预授后来五省版图 |
| 广州 G | 保住广州、处理商团危机、维持对东江的压力 | 核心城市与主力存续、危机解除，并达到有限地区战果或守备条件；不要求完成1925年东征 |

| 滇 Y、晋 J、湘 X、黔 D | 保持地区自主与关键交通 | 到达阶段结算时保住核心区和合理兵力，合作路线可附有限支援任务，不强制远征 |
| 川内 A/B | 保住实际控制区，应对同期已有竞争 | 只据核实的1924冲突设目标；不发动1925年统一全川路线 |

### 5.1 所有势力共用的统一路线

用户已确定“完成阶段目标后，所有势力都可通过事件选择统一全中国”。以下为本稿对选择流程的落实，目标区域及外交细节仍可修改：

1. 本方阶段目标完成后，保留完成记录，弹出一次“阶段大计”事件。此时尚未执行结束本局的胜利操作。
2. 选择“以此战果结束本局”：记录当前阶段成果，结算阶段胜利。
3. 选择“继续征战，统一全中国”：记录统一路线状态，保留同一局的势力身份、地图、军队、将领、资源与外交，先以消灭敌对阵营为当前任务，盟友领土暂不要求收回，不重新开局或自动发放地盘。
4. 敌对阵营清除后，若仍有占据中国目标区域的独立盟友，触发E11，再决定是否与盟友开战。选择继续统一才转入处理原盟友的阶段；选择维持同盟则立即结算联盟胜利并进入结局，不保留一个等待再次议定的进行中战局。
5. 选择继续的路线不按原阶段检定回合或历史善后节点强制结算；自身出局等正常失败规则仍有效。完成统一后再触发E12，进入统一胜利结局。

三个胜利结局均正常结束本局，区别在达成的战果及结局内容，不是只有统一才算胜利：

| 决策节点 | 选择或完成条件 | 结局 |
| --- | --- | --- |
| E10：完成阶段目标 | 以此战果结束本局 | 阶段胜利结局 |
| E11：消灭敌对阵营 | 维持同盟，结束本局 | 联盟胜利结局 |
| E12：完成中国统一目标 | 统一条件达成 | 统一胜利结局 |

本规则对所有开放可选势力相同：直、奉、冯、南方及地方集团、边疆力量，以及若开放的英法日苏等外国势力均可选择。外国势力的续战属于明确的架空玩法，不能在结算文字中冒充中国本土政治集团。现为背景的国家不因此自动开放，但日后开放时须拥有阶段目标和同等续战入口。

统一范围与完成条件初稿：

- 全国范围已由用户确定为“秋叶海棠”，按[统一边界规则](UNIFICATION_BOUNDARIES.md)制作独立逐格清单；不是全东亚，也不按开局控制或现代国界裁切。包含外蒙古、台湾等范围骨架，具体边界格、岛屿及租借据点按同一参考版图落格核对。
- 第一阶段只要求消灭敌对阵营，盟友拥有的中国区域不阻止这一阶段完成；它们留到E11选择后再处理。最终统一成功仍要求目标区域归玩家势力实际控制，或经明确的归附、整合事件纳入其控制，不能把仍独立的同盟自动当作归附。
- 不以消灭所有地图国家为条件；中国目标范围外的日本本土、印度支那及其他境外区域不作必占目标。外国玩家也必须完成中国范围的目标，不能用本国海外领土凑数量。
- 选择统一本身不自动对所有国家宣战。先保留盟友关系，消灭敌对阵营后才询问是否对盟友开战；决裂通过明确的双边关系结果执行，不以改阵营号暗中清空全部同盟。中立势力不因该事件自动成为敌人，其占有目标区域的处理及可能的外交整合另行讨论。
- 阶段目标完成记录在续战后仍保留，后续丢城不重复弹出E10。统一路线不是每次夺城重新选一次；保存、读档与路线目标保持一致。

这条共通路线增加的是玩家主动续战的选择，不继续扩展本剧本的历史事件年代，也不为每个小势力单独编一套后期全国战争剧本。

### 5.2 消灭敌对阵营后的盟友事件

按用户意见，流程是“完成阶段目标 → 选择统一续战 → 消灭敌对阵营 → 决定是否与盟友开战 → 继续争取最终统一”。盟友占地只在后续阶段处理，不在前一阶段要求玩家同时解决。

- 敌友以玩家当前的实际双边关系为准，不只看初始阵营号；“消灭敌对阵营”指清除秋叶海棠范围内敌对控制及驻军，不要求外国干预者在整个东亚地图出局。盟友、盟友的盟友或单纯中立者不自动当成敌人；不得把范围外剩余据点当作清敌未完成。
- 敌对阵营清除后，不先执行胜利结算；若仍需处理盟友，先弹E11。如果选择续战时已经没有敌对阵营，可直接进入该事件，不要求额外制造一个敌人。
- “继续统一，与盟友开战”：事件须列明将决裂的盟友及后果，确认后才使玩家与相关盟友敌对。同阵营也通过显式双边关系处理；不自动使所有第三方彼此开战，也不自动接收盟友军队或领土。
- “维持同盟，结束本局”：保留同盟作为本局最终政治格局，记录清敌战果，立即进入联盟胜利结局。该选项替代旧稿“暂缓统一后继续游戏”的安排，不再等待下一次决策，也不把联盟胜利写成完成全国统一。
- 若已没有需要处理的盟友，跳过E11，按尚未完成的中国目标继续判定；已经全部满足则直接触发E12。失去盟友的非中国境外地区不是强制任务。
- 是否同时向全部相关盟友开战，还是逐势力/逐阵营选择，作为下一步细化项；本轮先确定用户提出的先敌后友顺序，不暗定为一次全图背盟。

## 6. 按当前Rewrite接口落实的方法

依据2026-10-21现有 `rewrite/mod-kit/docs/porting/SCENARIO_EVENTS.md` 与 `Ew4.Core/ScenarioRules.cs` 核对；上轮“缺少换营与选项接口”的结论已过时。

| 规划内容 | 当前实现方式 | 需要避免的误用 |
| --- | --- | --- |
| 开局外交 | `always`直接事件，逐对`relation`设为neutral/allied/hostile | 不依赖阵营号推导全部关系；开局初始化必须早于正常行动 |

| 改阵营与关系 | 同一结果事务中写`camp`、所需`relation`和`state` | 显式关系优先于camp且持续保存；只改阵营不会清除原同盟 |

| 守军倒向 | 若确需表现，显式`unit_owner`并转移相应控制格 | 先核定哪些初始部队可转属，不能把整座城和所有玩家驻军无条件划走 |
| 路线串联与保存 | `scenario/`变量、`event_completed`及已存的选择记录 | 拒绝政变同样要写决定结果；读档不能再次弹出或重复发放 |
| 阶段选择与统一胜负 | 阶段达标先写`state`并弹窗；E10结束选项、E11维持同盟选项和E12统一完成均记录各自结局并执行`victory`；只有继续选项保留进行中状态 | `victory`会结束本局，不能在选择前提前执行，也不能使不继续选项留在进行中；三种结局文字按状态区分，具体呈现待制作 |
| 全国目标边界 | 按秋叶海棠逐格清单检查地块拥有者、范围内敌对驻军及当前关系；地图清单与事件条件的绑定待制作 | 不用全地图`faction_defeated`、总城市数或阵营号代替范围判断；境外据点不阻塞清敌、盟友决策与统一结算 |
| 图文呈现 | 关键转折用标题、正文、必要图片及按钮；普通变动直接通知 | 不在每次资源变化时弹窗，不让玩家连续替所有势力开军议 |
| 支援与危机费用 | 资源效果、资源条件及短缺分支，确有持续需要才用`repeat` | 本稿不增加没有设计目的的周期扣费；支援须有条件、代价和次数上限 |

本稿完成时观察到rewrite正在新增`ScenarioFactions.cs`及`faction_create/faction_revive`，因此不再断言“引擎不能动态新建国家”；这些正在变化的代码尚未由本轮验证，不作为C24初版的必要依赖。初版使用已存在的势力与部队；新增部队、建筑、改变AI战略目标和按按钮立即行军的能力仍须分别核对，不能从新建国家接口推断。外国若必须限制在据点防守，需另核AI策略；仅设同盟不能保证AI不会远征，因此该限制未解决前不承诺殖民军受控参战效果。

换营和关系切换前还须检查同格友军转敌军、敌军占据转交城市等情况。涉及同格冲突的效果不可直接提交；应通过部署和明确的转属规则解决，不删除玩家部队来强行通过校验。

所有规则打包到独立Mod的事件JSON/Lua，正式制作时以新宿主更新隔离运行副本。原包、`apk_work/`及`rewrite/`继续保持只读，不因本策划另起引擎开发。
