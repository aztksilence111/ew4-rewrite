# R 版暂停目标栏

2026-10-25。按用户批准的样式接入真实战役/征服，并按后续要求修正为暂停菜单固定居中，目标栏避让菜单。本地 ARM64 测试 APK 已构建及验证。

## 行为

- 暂停菜单始终保持屏幕正中心，四个原有按钮完整显示；修复构建编号挤出固定高度背板的问题。
- 目标栏从屏幕左边缘伸出，根据暂停框左侧余宽收窄。余宽不足时收短至暂停框上方；内容独立纵向滚动，支持滚轮/触摸，不移动暂停框。
- 手机反馈后取消目标栏摄像头安全区留白，顶栏/底栏背景从屏幕左边缘开始。正文18→16、标题23→20、分区/剧本20→17、说明/底注14→12、评价15→13、行距5→3，减少相应留白；暂停菜单保持原有尺寸及居中。
- 显示当前生效的原版或扩展胜利树，保留“满足任一 / 全部满足”、失败条件、回合上限及同时满足胜负的优先级。支持剧情动态替换及本地多人实际视角。
- 星级整数区间直接调用 `BattleSettlement.Stars` 推导，与实际回合限制相交。超过满星期限仅标记该档过期，保留其他通关机会；征服无有效5星区间时不伪造5星，多人不套单人评分。
- Lua 条件显示未知状态和作者说明，不额外执行脚本，不修改 RNG 或胜负。
- 目标栏隐藏时不请求/计算。打开暂停或可见期间收到提交状态时惰性检查；相同展示保留独立版本、同一批内容节点及滚动位置。新世界对象会重新投影候选，未细分条件依赖缓存。

## 作者接口

`rewrite/extension.json` 的 API≥2 可注册 `pauseObjectivesPresentation`。支持按实际剧本ID或 `*` 配置标题、分区顺序、宽高上限、字号、行距、动画、颜色、背板/星图和条件文字。首版为受约束的配置接口，不支持任意窗口树/HTML/JS/CSS。

详见 [接口](../rewrite/mod-kit/docs/porting/PAUSE_OBJECTIVES.md) 和 [示例](../rewrite/mod-kit/examples/pause-objectives/README.md)。配置参与原有 Mod 校验、指纹和导入导出流程；不新增存档格式。
