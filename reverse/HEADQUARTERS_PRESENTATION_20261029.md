# 指挥部完整Mod布局接口

2026-10-29。用户要求允许Mod按需定义显示效果、增加或减少按钮，不能只提供固定布局上的隐藏开关。

## 实现

- API 3新增 `extension.json.headquartersPresentation`，指向包内布局文件。支持名册、学院、任命分别替换，以及任意命名的自定义子页；未定义的内置页沿用原界面。
- 作者定义完整布局树、逻辑尺寸、嵌套、位置、缩放、图像、按钮材质、文字、颜色、透明度和旋转；包内PNG直接引用，无须新增图集。通用原生渲染器增加嵌入页面模式，既有弹窗保持原生命周期。
- 按钮节点路径绑定命令，数量和位置来自文件。支持返回、名册、学院星区、直接过滤、商店、公主、标签、任务/成就、刷新、两种货币招募、信息和自定义页；支持多个同命令按钮。
- 数据绑定提供账户货币、人数/容量、标题、学院刷新剩余量、已选候选和价格。名册可改变行数、卡片比例、间距及空槽/信息/晋升入口显示；卡片内部内容沿用现有将领卡片，并未承诺任意重写卡片模板或执行作者HTML/脚本。
- 命令沿用账户/交易后端，不绕过容量、余额、陈旧版本和任命校验。每页须有作者自定外观的back按钮；任命页只绑定back/info，实际派遣沿用卡片动作。
- 最小源码在 `rewrite/mod-kit/examples/headquarters-layout/`，包含无筛选/隐藏空槽的名册、管理子页及独立学院。完整字段见 [作者指南](../rewrite/mod-kit/docs/porting/HEADQUARTERS_LAYOUT.md)。
