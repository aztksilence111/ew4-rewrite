# 日本战国策略游戏的构图参考

2026-10-25。仅研究构图，未复用游戏美术或生成游戏底图。

![固定全国小地图对照](strategy_minimap_comparison.jpg)

| 作品 | 可核对的观察 | 对本项目的启发 |
| --- | --- | --- |
| 信长之野望·创造 / Sphere of Influence | 官方截图3右上角固定小地图：西日本沿横向展开，东北伸向右上；主画面是3D局部视图 | 保持东北斜向，同时使主要战区填满横向画幅 |
| 信长之野望·革新 | 官方截图1、2、4、5右上角全国小地图：日本主体占据紧凑横幅，西日本较平、东北上翘 | 可借鉴主体紧凑布局，但不能据此断言是某个精确刚性旋转角 |
| Sengoku | 官方截图2右下角全国小地图：保留较明显的东北—西南长轴，整体更纵长 | 同类游戏并无统一旋转角，也不都追求横向铺平 |
| 全面战争：幕府将军2 | 本次官方图库9、10、28等是3D局部战略视图，没有取得可测量固定全图旋转角的证据 | 不从3D镜头方位或俯仰角推断世界地图固定转了多少度 |
| 信长之野望·新生 | 本次官方图库主要是局部3D地形、菜单与战斗，没有可核对完整全国取景的画面 | 只作为局部地形层次参考，不列入全图角度证据 |

这些图没有提供统一投影和北向校准资料，不能将目测效果写成“游戏官方采用20°/30°”。取景范围、比例调整、投影和镜头都可能影响画面。上述全国小地图没有展示本项目要求的“完整北海道至与那国”长岛链，不能直接照搬长宽比。

本项目建议：保留此前选定的整体顺时针20°为基准；优先裁减不需要的地理范围，避免为了缩海而继续加大旋转角。红圈处实际为得抚岛，先裁出取景，保留择捉等较近岛屿；已生成新15°/20°/25°对照，见上级 `japan_no_urup/`，推荐新20°。
