# 启动资源检查优化

2026-10-27。已实现并验证源码，未生成新发行包或安装手机。

## 原因与调整

原缓存只省去解析及规则转换，每次启动依然枚举资源并逐个读取、计算全部资源的 SHA-256。本机 2,249 个运行时文件一次缓存检查读取 2,250 次、147,916,095 字节，包含图片、音频、字体，远多于 XML、BTL、BIN 本身。

- Android 使用安装包身份索引缓存：绑定安装更新时间、主 APK / split APK 的路径、长度、修改时间，以及引擎程序集版本。只有同一不可变安装包成功验证后，才复用资源清单和原验证结果，省去 AssetManager 递归目录枚举和包内资源重读。修改 APK 后重新安装、代码升级或索引损坏都会重新计算输入指纹；首次或验证凭据缺失时完整验证。
- 生成的转换缓存仍逐文件核对 SHA-256，损坏后从当前安装包重建；候选失败不覆盖成功缓存。该快速入口仅用于已安装 APK，电脑版可编辑目录继续逐文件计算内容哈希，保留 XML / BTL / BIN 修改检测及校验期间变更拒绝。
- 电脑版使用池化 64 KiB 缓冲流式计算非原始资源哈希，避免将整份图片、音频和字体分配到托管数组。没有用时间戳替代内容哈希。
- 首次校验复用已解析地图，减少一次地图 BIN 解析；不可变 APK 不再进行可编辑目录所需的第二次全量读取。完整地图格、剧本、规则和显示依赖校验仍执行。
- 原内容指纹、原版账户及变更玩法资料的存档隔离规则保持一致；已安装 Mod 的验证流程保持。

## 测量

Windows 桌面进程，原资源，三个预热样本取中位数。包路径使用与 Android 相同的共享方法，资源来自本机目录；不是手机耗时或整个进游戏耗时。字节数不含读取本地缓存凭据。

| 缓存检查方式 | 耗时中位数 | 资源读取次数 | 资源读取字节 | 托管分配量约 |
| --- | ---: | ---: | ---: | ---: |
| 原字节数组哈希路径 | 253.834 ms | 2,250 | 147,916,095 | 153.59 MB |
| 电脑版流式哈希 | 230.634 ms | 2,250 | 147,916,095 | 7.88 MB |
| 已验证不可变包路径 | 2.123 ms | 0 | 0 | 1.10 MB |

包路径本次约减少 99.2% 检查耗时；电脑版主要收益是分配量减少约 94.9%，耗时多轮有波动，不承诺显著加速。首次冷校验仍有规则 / JSON 解析开销，手机实际等待改善需新 APK 真机复测。
