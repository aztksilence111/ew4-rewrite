# 日本与神罗真实地理核对

2026-10-26。**结论：当前版本不能认定为符合真实地理，上一轮“地理核对通过”的表述范围过大。** 改小、减疏贴图改善了遮挡，没有解决山系轮廓、河谷、水系和城市移位。海陆大轮廓和部分大山系方向有真实数据依据，但成图及若干规则格仍有实质偏差。

## 主要发现

| 问题 | 实地图核对结果 | 证据 |
| --- | --- | --- |
| 近畿城市相对位置错误 | 现实中京都在大阪东北；当前京都被移到大阪西北。京都距候选原址29.3公里，大阪18.5公里、奈良19.6公里，后两者向东南／东方移动。近畿不能按现状视为真实城市布图。 | [近畿对照](kansai.jpg)，国土地理院底图 |
| 日本水系严重不全 | 列岛实际只导出了石狩川、利根川；信浓川、木曾川、淀川、北上川等没有导出。东北源数据中有最上川，但被名单筛选遗漏；其他河流也受全球小比例尺源数据覆盖限制。朝鲜半岛缺汉江等主要水系。 | [中部](central_japan.jpg)、[东北](tohoku.jpg)、[朝鲜半岛](korea.jpg)，`audit.json`实际导出河流名单 |
| 神罗重要支流缺失 | 莱茵干流、易北河、多瑙河、波河等存在，但缺美因河、摩泽尔河、内卡河、伏尔塔瓦河、因河等。法兰克福、布拉格、阿尔卑斯河谷因而缺少关键定位依据。 | [莱茵](rhine.jpg)、[波希米亚](bohemia.jpg)、[阿尔卑斯](alps.jpg) |
| 山脊、盆地和河谷层次丢失 | 阿尔卑斯弧、日本中部三大山系等大方向基本可对应，但均匀减疏的峰体和过弱的底层阴影不能清楚表达真实山脉边界、连续山脊和谷地。孚日、黑森林、波希米亚周围山地及日本东北对照尤其明显。 | [莱茵](rhine.jpg)、[波希米亚](bohemia.jpg)、[东北](tohoku.jpg)、[北海道](hokkaido.jpg) |
| 地形分类吞没局部盆地 | 甲府、松本盆地指定位置的最近规则格仍为山地。8公里半径P90采样将周围山坡并入，不能用来代表谷底本身。长野、因斯布鲁克等城市格虽被单格覆盖成平地，仍不能证明周边谷地通道连续。 | `audit.json`的`valley_samples`，附原始分型和最终BIN格类型；对照[中部](central_japan.jpg)、[阿尔卑斯](alps.jpg) |

海岸、琵琶湖等大湖及北德平原、关东平原、波河平原等大尺度位置总体可对应，不能据上述问题说所有数据都是随意生成。但“采用了DEM”与“成图、通行地形符合实地”是两个不同结论，之前混在了一起。

## 修正顺序

1. 先按实地图确定主要山系边界、连续山脊、低地和河谷通道；绘制应围绕这些结构，不能按每隔几格放一个山峰决定地理。
2. 补齐重要水系及支流，再核对山脉、河流、盆地和城市之间的相对位置。
3. 对主要城市约束原址和相对方向，设施在其外安排；“全部候选、较小图幅、所有陆上建筑中间至少3空格”与密集真实城市位置存在冲突，必须显式处理，不能靠大幅挪城后宣称准确。
4. 最后处理贴图大小、树林、标签和远近景。视觉简化应保留真实地形结构。

本轮按用户要求核查并保存偏差，未擅自合并城市、放宽已确认间距或再次改变取景。两图BIN、建筑、现代地图源、元数据及现行审阅页共11文件SHA256变化0；不是已经完成上述修复。
