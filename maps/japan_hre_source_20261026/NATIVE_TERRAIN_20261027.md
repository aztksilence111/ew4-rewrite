# 日本原版地形贴图修正

后续最新：[日本细化及神罗地形分区](REGIONAL_TERRAIN_20261027.md)。现已使用全部6种原版丘陵；日本分类保持，神罗按用户要求独立修订，以下两种丘陵及神罗不变是本修正阶段的历史状态。

2026-10-27。用户指出“山脉未连起来”后，曾尝试在邻接山地格间重复叠放山体。虽然不透明像素连接检查通过，画面却形成了梳齿状、锯齿状条带。这是错误的显示处理，已撤销；像素相连不代表视觉或地理合格。

当前恢复 `def_mapterrain.xml` 指定的原版 `mountain_1..6.png` 与 `hill_1..2.png`，不使用此前改变宽高比例的东亚派生山体，也不在格间补山。每个实际丘陵／山地格恰好一张原版精灵，位置为真实格心。只做等比例缩放：丘陵0.70、低山0.84、中山0.98、高山1.12，保留素材原始长宽比与六种山形。高低依据原有实测高程／起伏，地形种类和移动规则保持。

山系沿实际相邻山地格表现，自然重叠；河谷、盆地、平原及山口的断开保留，不再为贴图边缘强行接触添加重复山峰。当前未重新考证所有山系边界，不能声称全部真实山脉已连通。
