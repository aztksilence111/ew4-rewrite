## 选址口径

1. 沿用东亚近期的有名节点分类：工厂和马厩以独立有名地点填补城间空间，不给每城机械配套。港口为独立水面候选，保留城港组合。
2. 工厂表示矿冶、锻造、盐工或作坊功能候选，不能直接理解为现代工业厂。马厩按平原、盆地、内陆道路与驮运补给空间规划，不宣称每点都是史实马场。数量服从分布，未照搬东亚配额。
3. 坐标为人工地理初选，未完成逐点史料考证。日本采用便于识别的跨时期地名，包括北海道若干较晚发展的聚落。早期剧本需复核建城和开发年代；夕张、幌内、釜石、别子等不能直接套入战国。神罗约11至13世纪只定义广域地理骨架，柏林、阿姆斯特丹等须按剧本年份决定启用和名称。
4. 港口原始经纬度是港区参照点；绘图投影坐标在近岸水面上选候选位置，与城/设施符号分开。`*_points.json`保留原始经纬度、源投影位置、候选投影位置及近似偏移。候选水面不是最终海格、岸向、等级或航路验收。
5. 本轮不制作农田、政治边界、禁航海区、桥渡和山口。正式落格时还需检查小岛、海峡、邻格冲突、陆路与海路连通、辖区和性能。

## 构图和裁切

日本严格沿用已确认的整体顺时针15°、左界收50像素、1366×1052参考取景关系。以参考图经纬线的近似配准重绘自然地理，而非放大东亚运行图；本版配准不是正式游戏投影定案。保留北海道、择捉、国后、色丹、齿舞岛群和奄美至冲绳；得抚、久米、宫古及八重山不纳入。齿舞以岛群泊地表示，不虚构一座大城市。与原图的配准关系见生成器及此前`composition.json`。

按用户追加要求，朝鲜半岛补23个主要城市，包括汉城、平壤、开城、义州、江界、咸兴、江陵、全州、庆州和东莱等，含济州。日本列岛及附岛仍为151城，半岛只保留主要中心与通道节点，密度明显低于日本；不追加半岛工厂、马厩或港口。全图城市151→174、全部建筑239→262，原239点ID及位置保持。

以城市候选的地理坐标计算，最近邻城市距离中位数为朝鲜半岛72.1公里、日本列岛39.0公里；此项用于复核疏密，不等于最终六角格上的行军距离。

用户随后圈出俄远东滨海地区，补海参崴1城（131.885°E、43.115°N，别名符拉迪沃斯托克）；日本图总计175城、263处建筑。该点为1860年以后发展的城市，早期剧本须另核启用时期；本轮未追加当地工厂、马厩或港口。

神罗采用独立Lambert双标准纬线投影：中央经线12°、原点纬度50°、标准纬线44°/56°。按用户追加要求，将原2100×1980公里投影矩形收至1600×1750公里，取景面积减少32.66%；不是把图像横向压窄。完整保留丹麦及博恩霍尔姆、低地、瑞士、北意大利与托斯卡纳、波希米亚和必要的波兰匈牙利空间。大陆从东西及南侧自然出框，不制造海岸封边。

裁切仅使挪威背景点克里斯蒂安桑出框，神罗总候选369→368；原始`hre.json`仍保留该点。详情见`hre_crop.json`和`verification.json`。周边画入不表示其属于帝国，正式历史边界依剧本年份另核。
