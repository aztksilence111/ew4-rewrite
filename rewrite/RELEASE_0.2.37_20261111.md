# 0.2.37：部队移动与烟尘连续性优化

- 修复触屏高刷新率设备的移动绘制节奏：保留限帧余量，避免 90/144 Hz 屏幕被额外降为 45/48 次绘制。待机继续采用较低绘制频率。
- 移动从首个实际绘制帧起步，长帧参照原版最多推进 50 ms，避免起步跳过一段路或卡顿后突然跳动。移动演出等待同步调整。
- 烟尘沿经过的位置分散生成，粒子在模拟步之间连续显示；消退时保持透明层叠次序，减少成团跳动。沿用原版烟尘参数和纹理。
- Mod 循环移动步态从本次起点计时，随移动倍率同步；明确声明的静态动作保持有效。

包含 0.2.36 的全部功能与修复，规则 API 仍为 3。Android 为 ARM64＋x64 通用 APK，沿用原签名，可覆盖安装；Windows 请完整解压后运行 `Start-Web.cmd`。账户和存档请使用游戏内“设定→导出存档”备份。

已完成桌面浏览器、横竖屏触屏模拟、Canvas/Pixi 及实际陆军/舰船移动回归，直接核对原版移动函数与四份烟尘参数。高刷新率数字属于调度验证，不代表手机实测 FPS；本次未做 Android 设备验收。
