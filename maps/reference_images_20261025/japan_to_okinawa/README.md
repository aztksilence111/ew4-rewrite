# 南至冲绳本岛的日本取景示意

2026-10-25。按用户对“南端保留至冲绳，完整包含奄美—冲绳联系”的批注制作示意图，当前用于查看效果，未将其视作正式范围定稿，未制作游戏底图。

![全图示意](japan_okinawa_schematic.jpg)

- 保持整图顺时针20°，继续将得抚岛排除在取景外；保留北海道、择捉等邻近岛屿、日本主体及南九州—奄美—冲绳本岛。
- 宫古、八重山及与那国留在取景之外，按真实图片裁切，不抹除岛屿或涂海。
- 主图1484×976地图像素，较前版保留完整琉球的20°取景1707×1033，画幅面积减少约17.9%；该值不是海洋面积统计。
- 红虚线只是海上联系的地理示意，不是考证复原的历史航线，不表示陆桥、政治归属或实际游戏通行边。
