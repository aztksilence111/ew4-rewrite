## 核查与修改

| 项目 | 核查结果与本轮处理 |
| --- | --- |
| 局外页面切换 | 既有黑场只接入战役章节和征服选国部分路径，主菜单进入模式、返回主菜单、进入指挥部仍直接切换。现统一经全屏黑幕淡出160ms、切页、淡入180ms，沿用此前校准值；遮罩脱离缩放的菜单容器，手机竖屏也覆盖整个窗口，切换时阻止穿透点击。减少动态效果设置下直接切页，异常时释放遮罩和锁。 |
| 点击声音 | 旧内置仅26个战斗／行动 WAV，缺通用点击、返回、选择和弹窗资源及绑定。新增原 APK 的 `sfx_click`、`sfx_cancel`、`sfx_select`、`sfx_pop` 与原布局引用的 `sfx_lvup2`，共31个 WAV。通过统一事件入口覆盖动态／静态按钮和复选框，鼠标、触屏、键盘均单次触发；程序自动选中、禁用按钮和拖动不响。 |
| 原布局声音 | 保留原 `nativeAttributes.sound` 优先级，包含空字符串静音。弹窗读取布局 `sound`，默认弹窗声；设置窗口亦有打开声。自定义 `data-ui-sound` 可覆盖按钮。没有给原布局明确静音的交易按钮强行叠加点击声。 |
| BGM | 五首原版MP3早已导入，当前播放器的菜单 `battle1`、战局随机 `battle1..4`、失败 `defeat_music`、胜利保持和返回菜单规则已接。此次核验原字节、非静音PCM、真实播放时间推进、循环、独立音量、失败重取和前后台暂停恢复均通过，无需复制重复音乐或改选曲规则。 |
| 本地网页启动静音 | 用户已明确确认保留：localhost／127.0.0.1／[::1] 每次打开或刷新将音乐和音效设为0，本次会话可在设置调高音量，下次打开仍静音。Android ew4.local不适用，继续按保存的音量播放。此为保留的使用偏好，不是待修复故障。 |

原版依据为 `apk_work/original/assets/` 内原始WAV／MP3与 `layout.xml` 的 `sound` 属性；既有音乐原生函数定位见 [BGM还原记录](CAMPAIGN_MUSIC_RESTORATION_20261023.md)。页面时长沿用已有近似校准，未声称本轮重新逐帧标定所有原生页面。

- 原APK另有7个专用WAV未纳入当前资源闭包：`sfx_buff`、`sfx_build`、`sfx_build1`、`sfx_celebrate`、`sfx_flip`、`sfx_golddrop`、`sfx_slide`。其增益、建造、庆祝、翻页、奖励等精确触发仍需单独核对；没有仅复制文件就声称已接入。
- 原有弹窗缩放、章节气泡、侧栏横移、军事学院刷新动画继续各自使用原流程。本轮统一的是页面黑场与声音，并未把所有控件替换为淡入淡出，也未改变书签尺寸或拉伸底纹。
- 未做Android真机听音、系统音频焦点或各机型WebView验收；浏览器音频由真实媒体和PCM验证，自动测试通过 `--mute-audio` 避免外放。
