## 机制澄清

| 技能 | 代码的实际作用与说明要点 |
| --- | --- |
| 精准/突袭/军号 | 分别限炮兵/骑兵/步兵，攻击和反击时把目标回避减伤设为0；防御、装甲仍扣除。 |
| 围城术 | 攻击和反击建筑内敌军时使用`EvasionIgnoringBuilding`；其他回避修正仍适用。与对应兵种的全回避忽略同时存在时，不再增加此项收益。 |
| 地理学 | 陆地移动使用基本陆地消耗；渡河、上下船和通行限制仍适用。 |
| 防火术 | 驻守部队在战斗起火判定中有免疫；不会清除已有地块火灾或部队燃烧。 |
| 领导力 | 有效士气最低0；不把基础士气直接写成0。 |
| 密集攻击 | 步兵的基础攻击次数按100%生命值档位计算，攻击和反击均适用。 |
| 水手 | 免除陆军海上输出的0.8倍率，攻击和反击均适用。 |
| 后勤学 | 本部队粮耗为0，并免粮食短缺的士气惩罚；其他原因的士气惩罚仍可能发生。 |
| 攻击/防御战术 | 原版各10%；前者仅主动攻击触发，各次基础攻击取上限，后者仅被主动攻击触发，入伤降至1。 |

`回避`在r版战斗中为连续比例减伤，参与`raw * factor * (1 - evasion)`，不是随机闪避。普通攻击伤害仍会取整并保底1点。
