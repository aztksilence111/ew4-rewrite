# 0.2.16：战役同盟胜负与占领修复

2026-10-23。Windows Web独立包与Android ARM64 APK（版本码19），规则API2，沿用既有签名。精确源码、包大小和SHA-256见附件release-manifest.json与SHA256SUMS.txt。

- 战役本地多人共享同盟胜负，同盟合计占齐红点即可获胜；己方目标丢失而盟友仍有目标时不单独判负。征服维持单国胜负。
- 修正深入敌区、跨海占领后因不接壤而换主被撤回；接壤限制仅用于农田与要塞周边染色。
- 单人失败恢复指挥官失败对白，再进入原结算页；纠正国家败亡小窗被误当作整场失败页。
- 对齐结算汉字与数字，修正横竖屏切换时弹窗背景地图被拉伸，以及结算倍率未及时更新。
- 兼容旧未结束战役多人档，保留已结束历史结果；包内不含玩家账户或存档。

源码专项和三种屏幕尺寸浏览器检查通过；双端包、签名和远端附件核验见[发布进度](RELEASE_PROGRESS_0.2.16_20261023.md)。Android真机尚未运行，既有性能和闪烁规划不宣称完成。
