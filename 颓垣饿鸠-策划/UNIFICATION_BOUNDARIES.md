# 全国统一的边界与结局判定

更新：2026-10-21。状态：策划规则，不是已制作的地图或游戏配置。用户确定“全国”只按“秋叶海棠”范围计算；东亚底图其他势力可以干预，但其范围外领土不计入统一要求。适用于各征服，先在C24细化。

抗战例外：C37/C44先驱逐在华日方，再选择是否对盟友开战；统一秋叶海棠后还可选择击溃整个日本阵营，届时朝鲜、东南亚日方殖民据点及日本本土纳入远征任务，苏英法美作为同盟共同参战协助。此为另设的远征范围，不改变全国边界；远征以日本战争阵营全部被消灭为条件，不统计战果或按领土归属计分。流程及优先规则见[ANTI_JAPAN_ENDINGS.md](ANTI_JAPAN_ENDINGS.md)。本文件的一般清敌及统一结算规则不能覆盖该可选远征阶段。

## 1. 固定地理范围，不按国家身份筛选

- 统一目标以单独审定的“秋叶海棠”参考版图为边界，制作成固定的逐格目标清单；不采用整个东亚地图，也不采用现代国界或开局势力控制区作为替代。
- 大陆各地区、新疆、西藏、东北、外蒙古、台湾及澎湖属于本稿的范围骨架。外蒙古不是因为单独设国就被排除，台湾也不是因为开局归日本就被排除。
- 唐努乌梁海及相关历史边界、岛屿、港澳租借地等，按同一份“秋叶海棠”参考图逐项落格核对；不能在不同征服中因拥有者不同随意纳入或排除。本稿不虚构已取得或审定了精确边界文件。
- 日本本土、朝鲜半岛、印度及缅甸、印度支那、暹罗、菲律宾、阿富汗，以及秋叶海棠之外的苏联区域等，不因东亚底图上存在或参加战争而成为统一必占区域。
- 这里规定的是Mod的历史版图玩法范围，不把该范围当作各年份实际控制线。逐剧本政治归属仍按对应年份另做。

“谁拥有”与“是否在全国范围内”独立判断：外国占有范围内地块仍须处理；中国势力占有范围外地块也不能拿来凑统一数量。外国玩家的统一目标范围与中国玩家相同。

## 2. 地块分类与边界落实

| 分类 | 判定用途 | 规则 |
| --- | --- | --- |
| 范围内可控制陆地 | 全国统一领土目标 | 包含农村及边疆，不仅是城市；可控制且被纳入清单的地块都要判定 |
| 范围内城市及陆岸据点 | 统一节点、清敌及事件 | 城市、首都、设施、港口、租借据点按实际位置登记，不因建筑类别或外国旗帜漏掉 |
| 普通海面与不可控制格 | 地理参考或航路 | 不要求把整片海洋染色；地图无效格、不可控制格不生成不可能完成的占领条件 |
| 范围外地块 | 外部干预、补给与可选扩张 | 不计统一达成率，也不因敌对或同盟状态变成必占目标 |
| 尚待核定的边界格 | 人工复核 | 单独登记为待确认，不能默认为全计或全不计；未审定前不能声称全国边界已完成 |

判定清单独立于BTL辖区中心。一个辖区中心在范围内，不代表它指向的所有地块都在范围内；边界跨格时逐格处理，不沿最近城市归属把境外一起划入。城市与港口的地图坐标使用完整东亚地图索引，不使用截图裁剪编号。

后续制作应记录参考图版本、目标格清单、范围内重要城市及待核格；各年份共用同一地理口径，年份变化只改变开局拥有者。若采用不完整地图，缺失的重要目标地区须明确报告，不能把未制作等同已统一。

## 3. 先敌后友的判断只看范围内

此前“消灭敌对阵营”在结局判定中具体解释为：清除秋叶海棠范围内的敌对控制与有效驻军，不要求这些势力在整个东亚地图上出局。

| 节点 | 达成条件 | 不应阻塞的情况 |
| --- | --- | --- |
| 清敌完成 | 范围内没有敌对势力控制的目标地块，且没有其仍存续的敌对驻军 | 对方仍在范围外有领土、部队，或外交上仍敌对 |
| 盟友选择事件 | 清敌完成，且范围内仍有独立盟友控制目标地块 | 范围外盟友保有本土或殖民地；范围内盟友占地不阻止前一步清敌 |
| 最终统一 | 全部范围内目标地块归当前玩家或经明确整合纳入玩家控制，且没有范围内敌对驻军 | 境外仍有独立国家、敌对或友好势力、部队及未占城市 |

敌友以玩家当前双边关系判断；势力仅在境外驻军、未来可能再次进攻，不算当前仍占有全国目标。清敌后弹窗待选期间按既有事件规则暂停；接受续战后如敌军重新进入范围内，按当前状态重新判断，不能使用永久失效的“曾经清敌”标记提前授予结局。

盟友事件只列仍控制范围内目标的盟友。英国在印度、法国在河内或日本在东京的存在，不构成强迫对盟友开战的理由；如其仍占有范围内据点，则按实际据点列入处理。范围内中立势力也不会凭中立自动算作归附，最终统一仍需解决其实际控制；中立不自动宣战，具体接触、归附或战争事件另议。

一般征服保留已确定的三个结局：阶段达标不继续即阶段胜利；清敌后选择维持同盟即联盟胜利；选择继续并最终控制全国目标即统一胜利。前两种结局不冒称已完成全国统一。C37/C44按单列例外，在统一后先提供结束或击溃日本的选择，不直接自动结束。

## 4. 必须覆盖的边界案例

| 局势 | 应有判定 |
| --- | --- |
| 日本仍占台湾或大连，但东京未受攻击 | 范围内占地仍计入；收回范围内目标后无须为全国统一攻东京，但C37/C44主动选择击溃日本时须继续解决日本本土 |
| 法军丢失所有范围内据点，仍在印度支那驻军 | 不阻止清敌或最终统一，无须消灭法国全势力 |
| 英国同盟仍在印度，但已无范围内占地 | 不因英国存在而触发必须背盟的统一任务 |
| 外蒙古以独立势力存在并控制其范围内区域 | 纳入全国目标，不能因其设为境外背景而漏算 |
| 玩家远征占了朝鲜或河内，但范围内尚缺一个地区 | 境外战果不能补足缺失目标，不判统一 |
| 敌军失去范围内城市，仍控制范围内农村或驻有部队 | 尚未完成清敌，不能仅看城市数归零 |
| 所有范围内城市已占，但边疆或岛屿目标仍未完成 | 尚未统一，不用城市总量代替目标清单 |
| 范围内均属同营，但部分仍由独立盟友控制 | 可完成清敌并进入盟友选择，不直接判玩家完成统一 |
| 只剩范围外敌人或普通海面敌舰，范围内已满足全部统一条件 | 一般剧本可进入统一胜利；C37/C44先提供结束或远征选择，若选择远征，仍须击溃全日本阵营 |

本轮仅确定以上策划口径。逐格清单、边界预览及验证要在用户认可参考边界后制作，不在本轮修改原包、rewrite、独立Mod制作源或运行副本。
