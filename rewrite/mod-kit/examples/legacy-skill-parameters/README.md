# 原版技能数值模板

本目录是可打包的作者覆盖包；JSON 列出了本轮开放的 29 种原版技能，共 36 个参数，数值与原版现有实现一致。技能行为和触发顺序保留，只改变参数。需要支持 `legacySkillParameters` 的新版引擎；旧 API 2 引擎也可能因未知字段而拒绝此包。

1. 在作者副本中修改 `rewrite/definitions/legacy-skill-parameters.json`。可以只保留需要修改的技能和字段，其余自动使用原版值。
2. `rewrite/extension.json` 用 `apiVersion:2` 和 `legacySkillParameters` 注册该文件。已有扩展入口时合并这个字段，不要覆盖其他技能、事件或绑定。
3. 使用电脑工具打包、导入后启用，先在独立测试档中验证。后续改数值无需重编译引擎，但仍需重新打包、导入；没有实时热加载。

```powershell
.\Ew4.ModTool.exe pack "D:\mods\my-skill-balance" --id=my-skill-balance --name="技能平衡" --version=1.0
.\Ew4.ModTool.exe verify "D:\mods\my-skill-balance"
.\Ew4.ModTool.exe import "D:\mods\my-skill-balance"
```

例如只把间谍对要塞倍率改为 2、攻击战术概率改为 25%、建筑学费用改为原价的 40%：

```json
{
  "schema": 1,
  "skills": {
    "ew4.skill.4": { "multiplier": 2 },
    "ew4.skill.31": { "percent": 25 },
    "ew4.skill.30": { "percent": 40 }
  }
}
```

`ew4.skill.N` 使用内部 0 基编号，不能直接照抄界面文字表的编号。修改的是这项原版技能对所有持有者的参数，不会给任何将领自动增加技能；携带者仍由 XML 或 `commanderBindings` 决定。

校验范围：`multiplier` 为 0～100 的有限数；`bonus` 为 0～1000 的整数；`percent`、`gain`、`maximum` 为 0～100 的整数。折扣 `percent:40` 表示支付原价的 40%，而非减免 40%；`percent:0` 表示对应费用为零。教学上限只限制本次增加，不会降低已有能力。攻击上下界交叉时仍按原来的取样规则计算，不会自动改另一个参数。

不支持的技能 ID、该技能不支持的字段、重复键、拼错的字段、null、越界值会拒绝加载。旗手、地理学、防火、领导力、回避忽略、满血档攻击次数、水手、后勤学和围城术等机制不在本轮数值配置范围。

同 ID 若同时在 `skills` 中注册了完整扩展定义，该技能的原版行为会停用，这里的原版参数也随之失效，不会再叠加一次。经验装备仍优先于经验技能，原浮点计算、取整、随机取样顺序和折扣资源种类保持原样。玩家与 AI 使用同一组参数。

无配置的原版及旧 Mod 保留原账户和存档绑定。配置包会改变规则版本；修改参数后通常进入该 Mod 的新规则账户目录，旧档留在原目录，不能把旧局面强行套用新参数。r版对仍沿用原文的技能说明按当前参数显示具体数值；已自定义的文字表说明及完整扩展技能说明优先保留，作者需自行同步其中的数值。
