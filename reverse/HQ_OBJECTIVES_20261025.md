# 指挥部筛选、任务与成就接口

2026-10-25。共享 Web / Android 实现，未生成 APK、发布包或进行真机验收。

## 交互与布局

- 顶部固定“筛选 / 任务 / 成就”，统一原版蓝色按钮；按军事学院左侧的实际空间调整入口及选项尺寸。
- 筛选点击后向右展开“全选 / 一星区 / 二星区 / 三星区”，沿用地图模式菜单的平移动画经验；主入口始终显示“筛选”，选项显示当前选择。
- 展开项覆盖任务与成就位置；透明输入遮罩与选项分层。外部点击仅关闭展开层，长按也会拦截到松开，避免落到下层或军事学院。被覆盖命令同时禁用键盘激活。
- 两个列表沿用原版详情窗，显示纵向滚动条，支持拖动、滚轮、触摸和键盘滚动；R 版没有默认任务或成就内容。
- 隐藏成就由作者设置 `hidden: true`；未完成时列表接口不返回条目，达成后出现并可领取，领取后保持显示。

## 作者接口

完整格式及条件语义见 [OBJECTIVES.md](../rewrite/mod-kit/docs/porting/OBJECTIVES.md)。在现有扩展 `metagame` 规则增加 `objectives`，可组合局外将领/物品持有、隐藏战役解锁、战役星数、占领指定格、城市数、消灭部队数、胜利、回合与剧情事件条件，支持单局及部分跨局统计。

`reward` 支持 `medals`、`badges`、`items`（物品定义 ID 到数量的映射）和 `commanders`（将领定义 ID 数组）。物品无需在剧本或指挥部商店出现，将领无需进入军事学院抽取池；发放不改变商店或抽取配置。奖励将领采用定义初始属性和装备，自带装备一并计入库存。

领取检查账户修订号、完成状态、一次性回执、唯一装备/持有量、库存容量、名册及星级区容量。已拥有奖励将领或容量不足时保留待领取状态，货币、物品、将领和回执均不部分写入。奖励将领移出当前学院报价。活动对局同步账户，旧战局存档与重启不能重复领奖或覆盖新库存。

完成记录持久保留；跨局统计按战局与势力分开，城市按格集合、击杀取已见最大值、胜局按战局去重。仅统计单人战役/征服。新增字段兼容旧账户，默认空集合。接口不接受玩家提交奖励内容或完成状态。
