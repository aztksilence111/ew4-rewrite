# 地图图集的素材分辨率

地图 `sprite()` 绘制支持 `client/manifest.json` 的单个图集条目指定 `pixelRatio`。它表示每个地图逻辑像素使用多少素材像素；宽、高及 `refx`、`refy` 同时除以该值，替换高清素材时显示大小及锚点保持。

```json
{"x":0,"y":0,"w":416,"h":256,"refx":0,"refy":0,"pixelRatio":16}
```

该条目显示为26×16地图逻辑像素。未设置时原图集沿用1倍，`_hd`图集沿用2倍；无效值回退旧规则。图集图像和裁切坐标须对应，不能只修改宽高或比例。像素比例可独立于绘制缩放和设备像素比例。

这不是纹理尺寸无限制：整张图集仍受设备GPU的纹理尺寸与内存约束。C15候选使用每帧416×256，96帧排为3328×3072，低于4096边长；此处只是候选规格，Android实际设备尚须验收。原版光照仅约51×31像素，提高母版采样可改善字形、纹章、色带和透明边缘，但不会凭空增加真实布料细节。

当前为源码能力，旧已发行客户端不会自动理解新字段，须随新客户端发布后使用。不改变旗帜动画四帧规则；UI/动画库另有自己的比例规则，不受此字段影响。

高密度条目在缩小时由`Ew4Battlefield.spriteSample()`按实际绘制变换选择逐级二分的预滤波裁片，避免高分辨率图集仅靠GPU线性两点采样而使圆形、斜线、星条及文字重新出现锯齿。裁片先隔离再缩小，不采到相邻图集素材；各阶段按来源图像和裁切坐标缓存，放大时回到原始像素。普通/原版高清1倍和2倍条目不经过此分支，逻辑宽高和锚点不变。
