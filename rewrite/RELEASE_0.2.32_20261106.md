# 0.2.32 — 存档、外交与 Android 全屏更新

Android ARM64（versionCode 35）及独立 Windows x64 Web，规则 API 3。

- Android 全版本补齐沉浸全屏兼容标志，回前台恢复全屏，保留从屏幕顶边下滑临时显示状态栏；用于改善点击游戏顶栏时误触系统栏的情况。
- 双端加入存档 ZIP 导入、冲突确认及原始字节恢复副本；账户与战局按 Mod 和逻辑版本隔离，槽位及备份显示所属 Mod。
- 保留原概率劝降，加入付费招降；概率劝降可结合开局将领阵亡比例、阵营军团、兵力与建筑条件，确认框显示分项，旧档保留兼容规则。
- 完善将领实际星级保存与显示，以及商业星级定价；补齐兵种、移动和商业能力的非负整数支持。
- 完善空地分层、独立建筑施工回合、工兵施工后移动、站点每回合招募额度、动画循环及建造／死亡动作接口。
- 纳入新的通用战术技能接口、士气与部队归属处理，以及相关 Mod 文档和回归程序。

全部已实现的 R 版新改动随双端包交付。Mod 的人物策划、待评审美术和本地试玩工程仍按其独立制作状态维护；发行本体提供相应通用接口，不将待实现策划标为已完成玩法。

主菜单和对局暂停设定继续固定提供存档导出；包括坏档在内的账户、槽位和备份保留原始字节及校验信息，排除安装内容与启动缓存。

Android 应用 ID 和原签名保持。Windows 请完整解压 ZIP 后运行 `Start-Web.cmd`。附件提供 `SHA256SUMS.txt` 与 `release-manifest.json`。

Android APK 将核验实际包内容、签名连续性、ARM64 运行库及 16 KiB 对齐。本批未做 Android 真机安装与手势验收；厂商系统对边缘手势的识别仍需在实际设备确认。
