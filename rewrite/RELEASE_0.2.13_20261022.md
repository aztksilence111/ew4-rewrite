# 0.2.13 / 2026-10-22

更新移动端显示、动画表现、随机勋章及 AI 暂停操作，并整合 0.2.12 后的修复。

- Android 仅避让实际系统遮挡，修正横屏控件及中文显示；地图缓存减少拖动时的重复绘制，海军任命使用实际海面条件。

- 恢复士气分级显示、成长及晋升提示；按伤害和建筑条件随机掉落勋章，立即入账并防止读档及重复结算重领。
- 修复存档国家旗帜、空地撤回入口、保存提示及说明头像；占领触发事件或红黄目标后不能撤回，普通无事件城市仍可撤回。
- 暂停菜单阻止后续 AI 请求；当前行动提交后可保存，重开或退出可中断动画等待，并正确处理事件窗口层级。
- 批量复用士气占格查询，保留世界状态、存档及随机流结果；补充 Mod 表现、规则接口说明及反馈配置示例。

## 下载与运行

Web ZIP 为 Windows 10/11 x64 独立包，完整解压后双击 `Start-Web.cmd`，无需安装 .NET。升级前保留原 `saves/`，也可用 `--save-root` 指定旧存档目录。

APK 为 ARM64、Android 8.0 及以上，versionName 0.2.13、versionCode 16，沿用原开发证书。构建号高于此前本地测试 code15，可覆盖同签名旧包。

附件包括 Web ZIP、APK、`SHA256SUMS.txt` 和记录精确源码提交的 `release-manifest.json`；不含玩家档案或签名密钥。
