## 实现

| 项目 | 当前行为 |
| --- | --- |
| FB-01 战役存档国旗 | 新槽增加可选DisplayCountry显示元数据，按实际PlayerFaction及国家映射计算；保留原Country开局参数，战役仍可为null。旧槽从已有Session JSON中的playerFaction及剧本国家表恢复显示国家，列出旧槽不重写原文件；事件新势力映射复用当前前端国家解析。自动、手动、重启、读档再保存均覆盖。 |
| FB-03 空地撤回入口 | 按当前选中单位及后端selection.undo启用；选空地、其他不能撤回单位后禁用，点击回调也不再退回全局undoUnit。重新选中合法移动单位仍可撤回，保留即时归位及朝向。 |
| FB-09 保存提示拆行 | 提示的位图排版使用视口内的可用宽度，并收缩到实际字形宽；不再受原DOM文字的窄宽度限制。“已保存”三视口稳定单行，文字画布高度由34降为19 CSS像素；长错误仍按视口换行。培训中文映射保持，原手机其他菜单覆盖场景仍需同机验收。 |
| RF-01 将领图集校验 | commander字段及富文本commander块只按前端同一顺序查princesses_hd/commanders1_hd/commanders2_hd；不再将同名commandermark记录当作完整头像。实际Napoleon配置、未知将领拒绝和浏览器两种头像位置均已核对。 |
| 新撤回条件 | MovementHistory按实际归属变化阻止红/黄目标占领撤回。红圈使用Objective，黄圈使用原导入的BlocksTerritoryExpansion标记；经过己方目标但未改变归属不会因此锁定。移除同单位此前的移动记录，不能绕到旧记录撤销该次占领；之后正常移动仍可撤回到已占领目标。 |
| 占城事件与存档 | 同时检查原生event.triggered、脚本scenario.triggered/choice、实际触发列表及重复事件进度；事件发生后清理不可逆移动历史，确认对白不会恢复。保持同回合已攻击单位禁令，事件屏障不清除攻击锁。真实后端拒绝直接undo请求，存读档/重启后仍拒绝；旧槽已记录的红黄目标占领也被Available过滤。 |

普通城市未触发事件的占领仍可撤回；训练、资源、战斗与随机数不通过世界快照回滚。结束战局不提供撤回，避免撤销已结算胜利。
