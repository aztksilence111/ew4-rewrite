# 已选定：日本顺时针15°、左界收窄版

2026-10-25，用户贴出本版并确认“就这样就可以了”，作为后续日本大图的构图基准。整体顺时针15°，在原15°版基础上仅将左界向右收50像素，地图区域1366×1052；上、下、右边界不变。

保留北海道、北方四岛、日本主体及奄美—冲绳本岛；得抚岛、久米岛、宫古及八重山不纳入。左侧大陆残边按本图现状接受，不继续为裁净辽东一侧而牺牲冲绳。岛屿没有平移或单独旋转。仅确定构图，未制作正式游戏底图或整合游戏资源。

主图 `japan_okinawa_schematic.jpg`，无新增标注图 `japan_okinawa_clean.jpg`；参数、保留区域和原图哈希见 `composition.json`。红虚线仅示意海上联系，不是精确历史航线。北向上局部仍为地理背景参考，不定义本版保留范围。
