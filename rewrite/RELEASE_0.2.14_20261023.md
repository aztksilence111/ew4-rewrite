# 0.2.14（2026-10-23）

落实实机反馈 FB-14–17，Web 与 Android ARM64 共用本次修改。

- 界面、城市、地理标注及伤害数字统一使用离线内置字体，不再优先绘制原版 PNG 位图字。文字画布按界面缩放和设备像素密度重绘，保留内置字库缺字回退。
- 将领晋升窗口放大属性前后值及勋章费用，扩展数字容器高度，保留图标与按钮布局。
- 战场底边全部按钮、撤回、定位及左上资源/地块信息缩小 25%；暂停键保持原尺寸。显示与触控区域同步缩小。
- 招募编制空位改用低透明度，随卡片档位切换更新。API 2 新增 `formationCounts` 配置：各兵种档位可设置 1–99 编，超过三编显示士兵图标 × 数字；空配置保留原版默认。接口不自动增改战斗属性或生成额外招募档位，具体规则由 Mod 数据定义。工具包附空模板与说明。

Android：0.2.14 / versionCode 17，ARM64，最低 Android 8。沿用既有开发签名证书。

发行前执行核心、客户端、多编制导入与非法配置、独立 Web、浏览器多尺寸/高清文字及 APK 资源、签名和对齐检查。精确源码与文件摘要见附件 `release-manifest.json` 和 `SHA256SUMS.txt`。

本次没有 Android 真机执行，字体清晰度、晋升数字和触控尺寸仍需在实际安装设备上复验。
