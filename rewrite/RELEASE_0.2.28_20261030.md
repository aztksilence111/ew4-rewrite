# 0.2.28（2026-10-30）

Android ARM64 APK 与 Windows x64 独立 Web 版，规则 API3。

- 修复移动形成或解除夹击后士气未立即刷新，撤回移动同步恢复；保存和重载保留正确结果。
- 修复整编教学预览的能力图标、名称和星级排版，超过五星显示实际数量。
- 点击音效采用预解码音频缓冲，改善首击和连续点击延迟，保留静音、拖动及前后台恢复规则。
- 包含此前酒馆临时将领地图头像修复。
- Android 和 Windows Web 的主菜单及对局暂停设定均保留存档导出入口；账户、槽位及备份按原始字节导出。

Android 沿用原包名与签名，versionCode 31；Windows 解压后运行 Start-Web.cmd。升级前可导出存档备份。附件包含双端安装包、release-manifest.json 与 SHA256SUMS.txt。

验证包含双端构建、浏览器回归、包内资源与程序集核对、签名连续性及 16 KiB 对齐检查。未进行 Android 真机安装、听音或原生保存窗口验收。
