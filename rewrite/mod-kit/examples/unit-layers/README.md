# 空地分层最小示例

API 3 配置示例：将法国 0 级轻步兵 profile 映射到空层，只能普通对空攻击及反击，其余 profile 维持地表默认规则。
使用现有兵模和类别，没有历史航空兵种、专用飞机素材或新增将领能力；只供验证接口。
R 本体不读取此示例，只有作者主动打包、安装并启用 Mod 后才生效。需要包含 2026-11-02 分层接口的新构建，0.2.30 发行包不支持。

按已有 ModTool `pack/import` 流程使用。本例 `rewrite/extension.json` 是最小清单，已有 Mod 应合并 `unitLayers` 字段，避免覆盖其他扩展入口。不同国家、不同级别需要分别配置 profile ID。

字段、同格攻击射程、存档和尚未实现的航空机制见[接口文档](../../docs/porting/UNIT_LAYERS.md)。
