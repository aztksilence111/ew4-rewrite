## 空间口径

工厂／马厩与其他陆建保持4格距离；真实近邻城市允许不足4格，不再挪城凑间距。包含城港组合的近距离例外共日本66对、神罗48对，逐对保存稳定ID、格号、距离与原因。不能称全部城市均有三圈空地；审阅页布阵范围排除已被其他建筑占用的格。

常规海港位于可见水面；少数窄湾允许使用第二圈水格，偏移仍不得超24公里。安特卫普是小于格距的真实河港，泊位单格水面概化以`river_berth`单列，没有移往远处海岸。须德海坎彭港仍是现代湖面的历史海湾候选，不宣称已经完成中世纪岸线或海航验收。

狭窄小岛的布阵能力受地理限制，不为凑空地把小岛放大成大岛。可在邻近同一陆块内找到较宽位置的地点，优先移动到有至少 3 个空闲陆邻格的位置；仍不满足者由原生规则检查清单单列。

## 当前边界

本版是正式制作流程中的首轮地图源与落格审阅，尚未安装到游戏、覆盖现有地图或增加征服入口；没有势力、辖区、军队或历史城市等级。城市暂用 2 级、设施 1 级以检查原版外观，最终由具体剧本决定。

为保留全部候选并留出布阵空地，日本采用约9公里、神罗约8公里参考格距。两张全图均超过旧BTL建筑记录的有符号16位格号范围；不能把格号截断后声称能用。现代地图源和原生移动规则支持这些格数，但完整剧本接入需要单独处理大格号，以及加载、内存、AI回合与Android性能。当前未修改引擎格式，未打包APK或发行。

须德海历史岸线、逐水道海峡通行、历史桥渡、完整双语自然地理名称、细部地形及最终显示贴图仍需继续制作和审阅。部分极小岛屿按岛群格概化；不把本轮格心控制检查等同于完整的航路、长线战局或真机验收。
