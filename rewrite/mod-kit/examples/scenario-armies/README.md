# 事件增兵最小示例

本例用于内置第一征服，开局弹窗可选择给既有法国增兵，或创建地方国家并在同批结果中配置领土和带将新军；也可取消。将领定义 1 使用基础拿破仑条目，用于接口演示，不代表本剧本的史实增援。

将本目录作为覆盖包源码，使用 ModTool 的 `pack/import` 流程；不附测试包。需包含 2026-10-31 事件军队接口的新构建，既有 0.2.28 发行包不支持。

完整字段、原军转属、任免、和平撤编、费用及阻塞行为见[接口说明](../../docs/porting/SCENARIO_ARMIES.md)。更换剧本时须重新核对国家运行 ID、空闲落点、人物唯一性和兵种键；本例两条分支互斥，不能同时执行。
